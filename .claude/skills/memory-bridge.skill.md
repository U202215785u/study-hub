# 记忆桥接 Skill

## 触发
每次对话开始时自动加载。当用户说"继续之前的项目"、"更新记忆"、"记住这个"时强化触发。

## 核心职责
桥接 Study-Hub 五层记忆系统与当前 AI 对话，实现：
1. **对话开始时**：自动注入用户画像、活跃项目、工作流偏好
2. **对话进行中**：检测项目/工作流关键词，动态补充相关记忆
3. **对话结束时**：自动分层提取记忆，保存到对应层级

## 五层记忆模型

```
角色记忆 (Role)     — "我是谁"     → 长期稳定，每次对话注入
项目记忆 (Project)  — "我在做什么" → 按项目分组，涉及时注入
工作流记忆 (Workflow)— "我怎么做的" → 按任务类型，执行时注入
会话记忆 (Session)  — "刚才聊了什么"→ 单次会话，结束提炼
世界记忆 (World)    — "外部知识"   → RAG 检索，按需注入
```

## 硬约束

1. **注入不可见**：记忆注入以 [系统提示] 形式附加，不影响用户可见内容
2. **不主动收集角色/工作流记忆**：这两层必须用户确认后才写入
3. **会话记忆自动收集**：无需确认，自动保存
4. **项目记忆半自动**：检测到项目名时自动关联，但新项目创建需确认

## 工作流程

### 阶段 1：上下文注入（对话开始时）

```
1. 读取用户第一条消息
2. 调用 GET /memory/context_inject?q=用户消息&tool=当前工具名
3. 将返回的 full_prompt 注入到系统提示中
4. 格式：
   [系统提示：用户记忆画像]
   ===
   用户画像：全栈开发者，偏好 Vue + Python...
   活跃项目：个人博客（Next.js + MDX，路由已完成）
   工作流偏好：coding（TDD，详细注释）
   相关记忆：[项目] 讨论了三种路由方案...
   ===
```

### 阶段 2：动态记忆检测（对话进行中）

```
当用户消息包含：
- 项目名称（如"博客"、"那个项目"）→ 自动注入该项目上下文
- 任务类型（如"写代码"、"调试"）→ 自动注入相关工作流偏好
- "记住这个" → 调用 remember 工具存入角色记忆
- "继续"、"接着做" → 自动加载最近活跃的项目/会话
```

### 阶段 3：记忆收集（对话结束时）

触发条件（满足任一）：
- 用户说"更新记忆"、"同步记忆"
- 用户说"再见"、"谢谢"、"先这样"
- 检测到 5 分钟无操作

```
1. 收集本次完整对话
2. 调用 POST /memory/summarize_and_extract
3. 分析返回结果：
   - session_memories → 直接保存
   - project_memories → 保存，如果检测到新项目则提示用户
   - role_memories / workflow_memories → 提示用户确认
4. 输出记忆更新摘要
```

## 记忆确认对话框

当检测到角色记忆或工作流记忆时：

```
检测到关于你的新信息：
- "用户喜欢先写测试再实现代码"（习惯）
- "用户偏好使用 Vim 快捷键"（偏好）

是否记录到长期记忆？
[记住] [忽略] [编辑]
```

## 跨工具记忆共享

```
Kimi 对话结束 → 浏览器插件自动提取 → 存入 study-hub
Claude 对话开始 → MCP 工具 get_context_profile → 注入上下文

结果：在 Kimi 说的"我喜欢用 Vim"，Claude 自动知道
```

## 退出协议

当用户说"更新记忆"时：
1. 调用 summarize_conversation 提取本次对话记忆
2. 列出提取结果（按层分类）
3. 询问用户是否确认保存角色/工作流层
4. 用户确认后，输出"记忆已同步"

## 使用示例

**用户**：继续写那个博客
**AI**（自动注入）：用户正在做个人博客项目（Next.js + MDX），上次进度是路由已完成，待处理 contentlayer 配置。

**用户**：我喜欢在晚上写代码
**AI**：记住了。是否将此偏好保存到长期记忆？
**用户**：是的
**AI**（调用 remember + 标记为 role 层）：已保存。

**用户**：更新记忆
**AI**（调用 summarize_conversation）：
本次对话提取 4 条记忆：
- 角色：用户是夜猫子，喜欢晚上写代码
- 项目：博客路由已完成，使用文件系统路由
- 工作流：使用 TDD 开发
- 会话：讨论了三种路由方案

角色记忆和工作流记忆需要确认是否保存到长期记忆？
**用户**：确认
**AI**：记忆已同步。
