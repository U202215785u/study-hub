# 用户偏好：Skill 驱动工作流

> 记录时间：2026-06-06

## 偏好

用户倾向于 **Skill 驱动** 的创作工作流，而非传统工具导航。

## 具体表现

1. **要求创作中心全部换成 Skill** — 不要 Shotcut/GIMP/OBS 等工具网站
2. **要求分类：通用 + 平台专属** — 通用放上面，平台可切换放下面
3. **主动搜索新媒体 Skill** — 要求集成社区好用的新媒体运营 Skill
4. **接受"一键复制安装命令"的交互** — 不需要在页面内直接安装

## 推断

- 用户是 **AI-native 创作者** — 习惯用 AI 完成创作全流程
- 用户运营 **多平台账号** — YouTube/抖音/小红书/B站/公众号
- 用户重视 **效率** — 想要预设工作流，不想自己组合 Skill
- 用户愿意 **探索社区资源** — 主动要求搜索和集成第三方 Skill

## 建议

 future 对话中涉及创作/新媒体/内容生产时：
- 优先推荐 Skill 方案，而非工具方案
- 考虑多平台适配（国内平台优先）
- 提供工作流组合建议
- 引导用户使用 Skill 市场发现更多资源
