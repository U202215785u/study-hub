# 用户 L 的哲学偏好

## 核心洞察（2026-06-06）

> "向量匹配不是逻辑匹配，它做不到和人一样思考。"

这导致 Second Self 系统从"向量记忆"彻底转向"因果记忆"。

## 含义

L 重视：
1. **真正的理解** > **表面的相似**
2. **因果推理** > **统计关联**
3. **可解释性** > **黑盒效果**

## 对系统设计的指导

- 不要只追求"找得到"，要追求"想得通"
- 系统应该能回答"为什么"，不只是"是什么"
- 记忆检索应该返回因果链，而不只是相关片段

## 触发场景

当讨论 AI 记忆、检索、推理系统时，优先思考：
- 这是逻辑匹配还是数学匹配？
- 用户能看懂为什么返回这个结果吗？
- 系统真的"理解"了内容，还是只是在算距离？
