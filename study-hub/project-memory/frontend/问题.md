  - 修复：后端 `/documents` API 新增 `sort_by` + `sort_order` 参数（支持 created_at/title/char_count）；Home.vue 和 KnowledgeBase.vue 均添加排序下拉框（最新优先/最早优先/标题 A-Z/标题 Z-A）

- ISS-021: apiBase 硬编码 `http://localhost:8741` — high — frontend — 2026-05-30 — open
  - 影响：部署到非本机环境会失效
- ISS-046: 重新解析后队列任务详情空白 + 文档列表不刷新 — high — 2026-06-06 — **resolved**
  - 根因：① `viewDocument()` 不检查 API 返回的 `error` 字段，文档不存在时 `doc.title=undefined` + `doc.content=''` → 空白弹窗；② `reparseDocument()` 在新文档创建前就调用了 `loadDocuments()`，列表出现空窗
  - 修复：`viewDocument()` 增加 `if (doc.error)` 检查；`reparseDocument()` 改为启动队列轮询（`startQueuePoll()`），`fetchQueue()` 检测到新完成任务时自动调用 `loadDocuments()`
  - 文件：`frontend/src/views/Home.vue`
- ISS-048: 常用网站和 AI 启动器无法删除 — medium — frontend — 2026-06-06 — **resolved**
  - 根因：settings store 缺少 `removeLauncher` 方法，Home.vue 未暴露删除操作
  - 修复：settings.js 新增 `removeLauncher(i)` 方法；Home.vue 为常用网站和 AI 启动器卡片添加右上角 × 删除按钮，点击后 `confirm()` 确认再删除；AI 启动器卡片改为 `relative` 定位，内部用 `div` 包裹可点击区域避免删除按钮触发跳转
  - 文件：`frontend/src/stores/settings.js`、`frontend/src/views/Home.vue`

## 已解决问题
- ISS-019: 多代理同时构建导致 frontend/dist 产物随机覆盖 — high — 2026-05-30 — **resolved**
  - 根因：`build.sh` 使用固定临时目录 `/c/temp/study-hub-fe-build`，多代理并发构建无互斥，两个代理同时执行时互相覆盖源码和产物
  - 修复：`build.sh` 增加 `/c/temp/study-hub-fe-build.lock` 文件锁机制（标记文件 + 5分钟超时），第二个构建会等待第一个完成
  - 已知限制：异常退出（kill -9 / 断电）时 `trap cleanup_lock EXIT` 不会执行，锁文件可能残留最多 5 分钟。超时后自动清理。
  - 文件：`frontend/build.sh`
- ISS-015: 自动化解析缺少进度可视化与解析队列展示 — medium — frontend/automation — 2026-05-29 — **resolved**
  - 修复：后端细粒度步骤更新 + 前端卡片进度条 + 全局队列抽屉面板 + 3 秒轮询
  - 文件：`frontend/src/views/Home.vue`、`frontend/src/components/TaskStatusBadge.vue`、`backend/endpoints/automation.py`
- ISS-011: Vue 前端 Vite 构建在 Windows 下崩溃（esbuild 被 360 拦截）— critical — 2026-05-29 — **resolved**
  - 根因：`node_modules/@esbuild/win32-x64/esbuild.exe` 被 360 替换为 `RuntimeBroker` 代理程序，破坏 IPC 通信
  - 修复：`frontend/package.json` 添加 `overrides: { esbuild: "npm:esbuild-wasm@0.21.5" }`，使用 WASM 版本绕过拦截
  - 文件：`frontend/package.json`
- ISS-013: 项目路径含空格导致 Vite 构建失败（exit code 13）— critical — 2026-05-29 — **resolved**
  - 根因：路径 `study web` 含空格，Windows Git Bash 下 Vite ESM 模块解析崩溃，`npm run build` 无产物生成
  - 修复：构建前将 `frontend/` 复制到无空格临时目录（如 `/c/temp/study-hub-fe/`），构建完成后将 `dist/` 产物复制回原项目
  - 文件：`frontend/dist/`（构建产物目录）
