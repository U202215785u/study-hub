# 记忆系统模块问题

## 已解决

### ISS-031: 浏览器插件 CORS 问题
- **状态**: resolved
- **解决**: content script 请求改为通过 background.js Service Worker 代理
- **相关**: DEC-030

### ISS-032: 浏览器插件 Service Worker 通信问题
- **状态**: resolved
- **解决**: 添加 PING 心跳保活机制 + 错误降级处理 + alarms API 定期唤醒
- **相关**: DEC-030

### ISS-033: 扩展上下文失效
- **状态**: resolved
- **解决**: 添加 `isExtensionContextValid()` 检测，提示用户刷新页面

### ISS-034: Edge storage 权限问题
- **状态**: resolved
- **解决**: `chrome.storage.session` → `chrome.storage.local`

### ISS-035: 选择器匹配错误内容
- **状态**: resolved
- **解决**: 放弃固定选择器方案，改为可视化元素选择器由用户自定义
