# 记忆系统模块问题

## 开放问题

### ISS-031: 浏览器插件 CORS 限制 [已解决]
- **现象**: Kimi 页面直接 fetch localhost:8741 返回 `Failed to fetch`
- **根因**: 浏览器 CORS 策略阻止网页跨域访问本地服务
- **解决**: content script 请求改为通过 background.js Service Worker 代理
- **文件**: `extension/background.js`, `extension/content.js`, `backend/main.py`

### ISS-032: 浏览器插件 Service Worker 连接失败 [待验证]
- **现象**: 点击 🧠 记住这段 显示 `Could not establish connection. Receiving end does not exist.`
- **根因**: Service Worker 可能未启动或已被 Chrome 终止
- **修复**: 
  1. 添加 PING 消息处理到 background.js
  2. content.js 添加扩展可用性检查
  3. 添加 Service Worker 心跳保活机制
- **文件**: `extension/background.js`, `extension/content.js`
- **验证步骤**:
  1. 移除并重新加载扩展
  2. 打开 Kimi 页面按 F12 → Console
  3. 输入 `chrome.runtime.sendMessage({type:'PING'},console.log)`
  4. 应返回 `{pong: true}`
