## 当前状态
Wiki 编译引擎、页面管理、向量搜索、学习路径生成功能正常运行。

## 最近变更
- 2026-05-30：Wiki 左侧边栏重构 — 分类改为树形索引（自动识别层级关系如 `AI工具/项目`），下方增加文章列表区域，解决"没地方点文章"的问题
- 2026-05-30：Wiki 右侧预览面板 — 点击文章内 wikilink 时右侧弹出 420px 预览面板（可继续深入/切换为主文章/关闭），主阅读区默认全屏沉浸，外联仍新标签页打开
- 2026-05-30：Wiki 内联展示修复 — `openPage` 改为通过 API 获取完整内容（解决列表数据不含 content 字段导致右侧空白的问题），恢复左右分栏内联阅读模式
- 2026-05-30：Wiki 页面全屏化 — App.vue 中 Wiki 路由隐藏 NavBar/SystemStatus，Wiki.vue 去掉圆角边框和边距限制（`h-screen` 占满视口），移除右上角导航链接框选
- 2026-05-30：新增 Markdown 封面图功能（cover_image）— wiki_pages 表新增 cover_image 字段，后端 API 支持读写，前端 WikiPage.vue + Wiki.vue 展示封面图，编辑弹窗支持 6 张内置封面选择 + 自定义 URL + AI 生成（GrsAi Nano Banana 2）。内置图库存放于 frontend/public/covers/（6 张 Unsplash 精选）。
- 2026-05-30：AI 封面图生成功能 — 编辑弹窗新增 ✨ AI 生成按钮，支持自定义提示词或自动根据文章标题+内容生成，调用 GrsAi Nano Banana 2 API（¥0.065/张），16:9 宽屏输出，生成时间约 20-25 秒
- 2026-05-30：Wiki.vue 主页支持 inline 编辑（ISS-033）— 顶部工具栏新增 ✏️ 编辑按钮，编辑弹窗支持封面图/标题/分类/标签/内容修改，保存后自动刷新当前页面和左侧列表
- 2026-05-30：封面图渲染样式优化 — 封面图作为 Markdown 内容的一部分（`pageContentWithCover`），CSS 第一张图片全宽（`width: 100%`）、max-height 360px、无圆角，与参考样式一致
- 2026-05-30：修复 Wiki 页面内容区缺少一级标题问题 — 双保险方案：A) 前端 `Wiki.vue`/`WikiPage.vue` 渲染时自动注入 `# {title}` 一级标题；B) AI 编译 prompt（`COMPILE_SYSTEM`）新增规则：每个页面 `content` 必须以 `# {title}` 一级标题开头
- 2026-05-30：修复封面图保存后 404（ISS-023）— 后端仅 title 变化时重新 slugify，保持原有 `-id` 后缀；前端保存成功后若 slug 变化自动 `router.replace` 更新 URL
- 2026-05-29：automation-owner 通知 — documents 表新增 `idx_doc_source_hash(source, content_hash)` partial unique index，用于阻止摘要文档重复入库。Wiki 编译侧无影响（只读 documents 表），但重启后端后索引生效。
