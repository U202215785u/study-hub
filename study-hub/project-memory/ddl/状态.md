## 技术选型

| 用途 | 选择 | 理由 |
|------|------|------|
| 拖拽排序 | `vuedraggable` v4 (SortableJS) | 4,500+ star，7KB，Vue 3 原生支持 |
| 日期处理 | `date-fns` | 按需引入，轻量 |
| 倒计时 | 后端计算 `days_left` | 比前端倒计时组件更简单可靠 |
| 甘特图 | ❌ 不引入 | 对个人 DDL 面板太重，纯 CSS 时间线替代 |
| 日历视图 | ❌ 不引入第三方日历库 | date-fns + CSS Grid 自建，更轻量更可控 |

## 历史决策

- **2026-06-06**：DDL v2.0 时间规划系统 —— 日/周/月/列表四种视图 + 数据库迁移。选型结论：不引入第三方日历库，date-fns + CSS Grid 自建。SQLite ALTER TABLE 不支持 CHECK 约束（迁移时移除）。
