## 开放问题
- ISS-006: 任务队列 `_tasks` dict 只增不减 — medium — 2026-05-29 — open
  - 影响：长期运行内存泄漏
  - 建议：定期清理或限制最大历史任务数
- ISS-008: 小红书 HTML 解析依赖 `window.__INITIAL_STATE__` — medium — 2026-05-29 — open
  - 影响：小红书改版会导致解析失败
  - 建议：增加 fallback 解析策略
- ISS-009: ffmpeg-python 与 ffmpeg 二进制是独立依赖 — high — 2026-05-29 — open
  - 影响：只装 pip 包没装二进制时 ASR Level 2 会崩
  - 建议：启动时检测 ffmpeg 可用性，提前报错
- ISS-015: 自动化解析缺少进度可视化与解析队列展示 — medium — frontend/automation — 2026-05-29 — **resolved**
  - 修复：
    1. 后端 `_process_single_task` 增加细粒度步骤更新（extract_meta / summarize / import），新增 `_init_task_steps` / `_update_step` 辅助函数
    2. `queue_status` / `task_status` 接口返回 `steps` + `current_step`
    3. 前端解析卡片增加步骤进度条（done/running/pending/error 四态）
    4. 新增全局解析队列抽屉面板（统计/任务列表/步骤条/查看文档）
    5. 3 秒轮询 `/automation/queue/status` 实时刷新进度
  - 文件：`backend/endpoints/automation.py`、`frontend/src/views/Home.vue`、`frontend/src/components/TaskStatusBadge.vue`

## 已解决问题
- ISS-002: Claude Code 路径硬编码为 Windows 绝对路径 — high — 2026-05-29 — **resolved**
  - 根因：Claude Code CLI 路径写死在代码中
  - 修复：改为配置项或自动检测 claude 命令位置
  - 文件：`backend/endpoints/automation.py`
- ISS-016: 抖音口令格式链接无法解析 — high — 2026-05-29 — **resolved**
  - 根因：`DouyinProcessor.parse_share_url()` 正则只匹配 `http://`/`https://` 开头的标准 URL，抖音口令中的 `v.douyin.com/xxxxx`（无协议头）无法识别
  - 修复：在 `automation.py` 中新增 `_preprocess_douyin_input()` 函数，提取无协议短链并补全 `https://`，再传给 `parse_share_url()`
  - 文件：`backend/endpoints/automation.py`
  - 备注：若口令中完全不含 `v.douyin.com/xxxxx` 或 `www.iesdouyin.com/...`（如用户只复制了标题文本），仍需要用户重新复制完整分享文本
