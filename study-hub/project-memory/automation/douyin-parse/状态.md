# 抖音解析子模块状态
最后更新：2026-06-06

## 当前状态
使用 `DouyinProcessor`（来自 `douyin_mcp_server.server`）解析分享链接获取视频元数据。

## 新功能：抖音收藏批量导入（2026-06-06）

### 两种使用方式

**方式一：浏览器插件采集**
1. 用户在浏览器打开抖音收藏页（需已登录 https://www.douyin.com）
2. 点击扩展图标 → 看到「📹 抖音收藏导入」区域
3. 点击「采集当前页收藏」→ 自动滚动加载更多 → 提取所有视频链接
4. 链接发送到后端 `/automation/queue` → 逐条解析

**方式二：前端批量粘贴**
1. 主页抖音模块点击「展开」批量导入 → 粘贴多个链接（每行一个）
2. 点击「开始解析」→ 批量提交后端队列

### 技术实现
- **content.js**: 新增 `extractDouyinVideoLinks()`（四策略提取）+ `scrollAndCollectDouyinFavorites()`（滚动加载 + 智能停止，连续5次无新内容停止）
- **popup.js**: 新增 `checkDouyinPage()` 检测当前页面 + DOUYIN_FAVORITES_RESULT 消息监听 + 批量提交逻辑
- **popup.html**: 新增抖音收藏导入区域（采集按钮 + 状态显示 + 链接列表）
- **Home.vue**: 抖音模块新增批量导入 textarea（可展开/收起）+ `runAutomation()` 支持 `inputs` 数组
- **后端无需改动**: `/automation/queue` 天然支持 `inputs` 数组批量提交

### 设计决策
- 选择浏览器插件方案而非服务端爬虫：利用用户已有登录态，避免反爬
- 采集流程：先快速抓取可见链接（即时反馈）→ 再滚动加载更多（完整采集）
- 滚动停止策略：连续 5 次无新链接即停止，默认最多 30 次滚动

## 关键技术点
- 分享链接 → video_id → 视频 URL + 标题
- ASR 三级降级从 `automation.py:_extract_douyin_raw()` 调用
- Level 1 直接传视频 URL 给火山引擎 BigModel ASR（2h/100MB）
- Level 2 下载视频（120s 超时）→ ffmpeg 提取音频（64k mp3）→ ASR

## 已知问题
- ffmpeg-python 和 ffmpeg 二进制是独立依赖
- 视频下载可能超时（120s）
- 火山引擎优先，.env 未配置时自动回退 DashScope + 55s 截断
- **口令格式链接无法解析** — 已修复（`_preprocess_douyin_input()`）
- **MCP 工具直接调用缺少预处理** — 已修复（SKILL.md 第零步）
- **链接过期 / 抖音反爬** — 暂无根治方案
- **收藏页采集限制** — 抖音收藏页是无限滚动，依赖浏览器 DOM 提取，如果页面结构变化需更新选择器
