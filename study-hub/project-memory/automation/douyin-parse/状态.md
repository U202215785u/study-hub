# 抖音解析子模块状态
最后更新：2026-05-29

## 当前状态
使用 `DouyinProcessor`（来自 `douyin_mcp_server.server`）解析分享链接获取视频元数据。

## 关键技术点
- 分享链接 → video_id → 视频 URL + 标题
- ASR 三级降级从 `automation.py:_extract_douyin_raw()` 调用
- Level 1 直接传视频 URL 给 DashScope
- Level 2 下载视频（120s 超时）→ ffmpeg 提取音频（64k mp3）→ ASR

## 已知问题
- ffmpeg-python 和 ffmpeg 二进制是独立依赖
- 视频下载可能超时（120s）
- DashScope 10MB 限制（Level 1 失败的主要原因）
- **口令格式链接无法解析** — `DouyinProcessor.parse_share_url()` 只匹配 `http://`/`https://` 开头的标准 URL，抖音口令（如 `v.douyin.com/xxxxx` 无协议头）会抛出 `ValueError: 未找到有效的分享链接`
  - 修复：在 `automation.py:_extract_douyin_raw()` 中新增 `_preprocess_douyin_input()` 预处理函数，提取无协议短链并补全 `https://`
  - 文件：`backend/endpoints/automation.py`
  - 日期：2026-05-29
