# ASR 子模块状态
最后更新：2026-05-29

## 当前状态
使用阿里云百炼 DashScope Qwen-3-ASR-Flash 模型。

## 关键技术点
- 模型：`qwen3-asr-flash`
- API key：从环境变量 `DASHSCOPE_API_KEY` 读取
- 支持语言参数（主要用 `zh`）
- 输入支持：URL、本地文件路径（自动加 `file://` 前缀）

## 已知问题
- 阿里云百炼欠费时返回 "overdue" 或 "access denied"
- 大文件（>10MB）直接传 URL 可能失败
- API 调用失败时返回的错误信息不够用户友好

## 健康度
🟡 依赖第三方服务可用性和配额
