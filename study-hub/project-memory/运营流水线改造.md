# 运营流水线改造记录

## 时间
2026-06-06

## 变更内容

### 1. 运营工作台（CreatorHub 重写）
- 从"Skill 展示墙"变为真正的运营工作台
- 6 步流水线：选题 → 矩阵号 → 口播稿 → 剪辑 → 封面 → 发布
- 仪表盘统计：项目数、已发布、待选选题、矩阵账号

### 2. 后端 API（27 个接口）
文件：`backend/endpoints/operations.py`

| 步骤 | 接口 | 功能 |
|------|------|------|
| 找选题 | POST /operations/topics/ai-discover | AI 自动发现选题 |
| | POST /operations/topics | 手动添加选题 |
| | GET /operations/topics | 列出选题库 |
| 矩阵号 | POST /operations/accounts | 添加平台账号 |
| | GET /operations/accounts | 列出矩阵账号 |
| 口播稿 | POST /projects/{id}/script/generate | AI 生成口播稿 |
| | POST /projects/{id}/script/update | 保存/编辑口播稿 |
| | POST /projects/{id}/script/polish | AI 润色口播稿 |
| 视频剪辑 | POST /projects/{id}/video/editing-plan | 生成剪辑方案 |
| | POST /projects/{id}/auto-edit | **FFmpeg 自动剪辑** |
| | POST /projects/{id}/video/capcut-export | 剪映导出指南 |
| 封面图 | POST /projects/{id}/cover/generate | AI 生成平台适配封面 |
| 多平台发布 | POST /projects/{id}/publish | 生成各平台适配文案 |
| | POST /projects/{id}/auto-publish | **一键发布（Postiz/n8n）** |
| | POST /projects/{id}/publish/confirm | 确认已发布 |
| 语音合成 | POST /projects/{id}/tts/generate | **火山引擎 TTS** |
| | GET /operations/tts/voices | 列出可用音色 |
| 项目管理 | POST /operations/projects | 创建项目 |
| | GET /operations/projects | 列出项目 |
| | GET /operations/projects/{id} | 项目详情 |
| | POST /projects/{id}/status | 更新状态 |
| 仪表盘 | GET /operations/dashboard | 运营数据统计 |
| 发布配置 | GET /operations/publish/config | 查看发布配置状态 |

### 3. 数据库表（3 个新表）
文件：`backend/database.py`

- `content_projects` — 内容项目全生命周期
- `topic_ideas` — 选题库
- `platform_accounts` — 矩阵账号管理

### 4. 火山引擎 TTS 语音合成
- 口播稿一键转音频
- 5 种音色：中文女声/男声、新闻女声、配音女声/男声
- 支持语速、音调调节
- 自动清理口播稿中的表演提示（【停顿】【重音】等）

### 5. FFmpeg 自动剪辑
- TTS 音频 + 黑色背景 + 自动字幕 = 基础口播视频
- 字幕从口播稿按句分割生成 SRT
- 支持 720p/1080p/4k 分辨率
- 剪映暂未开放 API，提供详细导入指南

### 6. Postiz/n8n 一键发布
- 配置了 Postiz API Key → 自动调用 Postiz 发布
- 配置了 n8n API Key → 自动触发 n8n 工作流
- 都没配置 → 生成各平台文案供手动复制

### 7. Workflow 模板
文件：`workflows/运营流水线-口播视频.yml`
- 从选题到多平台发布的 7 步自动化工作流

## 完整运营流水线

```
1. 找选题 → AI 发现或手动添加
2. 创建项目 → 关联选题
3. AI 写口播稿 → 编辑润色
4. 语音合成 → TTS 生成音频
5. 自动剪辑 → FFmpeg 生成带字幕视频
   （或：生成剪辑方案 → 手动拍摄 → 剪映精剪）
6. AI 生成封面 → 平台适配尺寸
7. 一键发布 → 各平台文案 + 自动/手动发布
```
