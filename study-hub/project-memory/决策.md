- DEC-028: Markdown 排版系统改用 Kami 原版 margin 模型 — 解决 Flow 间距系统与中文内容不匹配的问题 — 2026-05-30 — active
  - 背景：Flow 系统（`> * + *`）把所有元素一视同仁，导致标题前后、段落前后、引用块前后间距无法精确控制，中文长段落下显得拥挤
  - 变更：
    1. 抛弃 Flow 变量系统（`--flow-space` / `--flow-space-loose` / `--flow-space-tight` / `--flow-space-medium`）
    2. 每个元素照搬 Kami 原版 margin（p `mb: 10pt`、h2 `margin: 24pt 0 8pt`、h3 `margin: 18pt 0 6pt`、ul `margin: 6pt 0 10pt`、blockquote `margin: 12pt 0` 等）
    3. line-height 1.55 → 1.75（中文舒适阅读）
    4. 列表项之间去掉额外 margin，纯靠 line-height 撑开（Kami 原版）
    5. 列表 marker 改为藏青色（Kami 原版）
  - 相关：DOM 结构修复（MarkdownRenderer.vue 按钮外移，避免破坏 `.markdown-content` 直接子元素关系）
- DEC-029: 五层记忆系统 v2 架构设计 — 解决"跨 AI 工具失忆"核心痛点 — 2026-05-30 — active
  - 背景：用户在不同 AI 工具（Kimi/Claude/ChatGPT）间切换时完全失忆，每次都要重复项目背景、个人偏好、技术选型
  - 五层模型：
    1. 角色记忆（Role）— "我是谁"：个人偏好、习惯、能力边界
    2. 项目记忆（Project）— "我在做什么"：项目进度、决策、技术栈
    3. 工作流记忆（Workflow）— "我怎么做的"：开发流程、工具偏好
    4. 会话记忆（Session）— "刚才聊了什么"：单次对话上下文
    5. 世界记忆（World）— "外部知识"：知识库、文档、收藏
  - 收集策略：会话记忆自动收集 → AI 提炼 → 分层存储（角色/工作流需用户确认）
  - 注入策略：对话开始时自动注入用户画像 + 活跃项目 + 相关工作流
  - 跨工具共享：浏览器插件（Kimi 等网页）+ MCP Server（Claude Desktop）+ Skill（Kimi Code CLI）统一访问同一 SQLite 后端
