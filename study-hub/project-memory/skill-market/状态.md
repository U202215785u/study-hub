## 技术实现

- 前端：`frontend/src/views/SkillMarket.vue`
- 后端：`backend/endpoints/skills.py`
- 同步：`backend/core/skills_sync.py`（awesome-claude-code CSV）
- 扫描：`backend/core/skills_scanner.py`
- 数据库：`community_skills` + `local_skills` 表

## 文件清单

```
frontend/src/views/SkillMarket.vue          # Skill 市场页面
frontend/src/stores/skills.js               # Skill 状态管理（预留）
backend/endpoints/skills.py                 # Skill 管理 API
backend/core/skills_sync.py                 # 社区 Skill 同步逻辑
backend/core/skills_scanner.py              # 本地 Skill 扫描器
```

## API 端点

| Endpoint | 功能 |
|----------|------|
| GET /skills/community | 社区 Skill 列表 |
| POST /skills/community/sync | 手动同步 |
| GET /skills/local | 本地 Skill 列表 |
| POST /skills/local/install | 安装 Skill |
| POST /skills/local/{id}/toggle | 启用/禁用 |
| DELETE /skills/local/{id} | 卸载 |
