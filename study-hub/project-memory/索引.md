## 三、功能角色 Skill（触发指令见各文件）

> ⚠️ **重要**：在 Kimi 对话框中，**不要**用 `@文件路径` 加载 skill——这会被客户端解析为 ReadFile。
> 正确用法：**说"加载 xxx skill"或"按 xxx 规则执行"**，agent 会主动读取并按规则工作。

| 角色 | Skill 文件 | 触发场景 | 核心职责 |
|------|-----------|---------|---------|
| 管家 | `.agents/skills/管家.skill.md` | "不知道该找谁"、任何需求开头 | 路由判断：读状态 → 四维路由 → 建议加载谁 |
| 产品经理 | `.agents/skills/产品经理.skill.md` | 需求模糊、一句话说不清 | 展开需求 → 决策点 → 边界情况 → PRD |
| 架构师 | `.agents/skills/架构师.skill.md` | 新功能/跨模块/需要架构设计 | 技术方案、模块划分、接口设计 |
| 实现者 | `.agents/skills/实现者.skill.md` | 代码写完了要检查 | 写代码、执行计划、测试验证 |
| 审计者 | `.agents/skills/审计者.skill.md` | 代码写完了要检查 | 代码审查、验收标准验证 |
| 调试者 | `.agents/skills/调试者.skill.md` | 东西坏了不知道原因 | 系统性排错、根因分析 |
| 照料者 | `.agents/skills/照料者.skill.md` | 代码质量巡检 | 规范检查、性能审查 |
| 体验走查 | `.agents/skills/体验走查.skill.md` | "走查 xxx 模块"、"测体验" | 按尼尔森十原则执行体验测试 |
| 协作向导 | `.agents/skills/协作向导.skill.md` | "这套系统怎么用"、"该加载谁" | 解释系统规则、使用说明书 |
