## SH.HOME

- 页面路由：`/`；固定开发地址为 `http://127.0.0.1:5181/`。
- 布局契约：以 `1440×980` 为基准舞台，固定 `8×4` 网格、九张模块卡片和 `16px` 卡片内容边距；PC 与 16:9 优先，超宽屏等比居中留白。
- 页面职责：`Home.vue` 负责 API、路由、存储、弹窗和副作用；九张 Widget 只接收展示数据并抛出标识事件。
- 模块能力：隐藏、恢复、拖动排序，以及知识库、自动化、创作、工作流、日历和任务事件契约均保留。
- 验证入口：`frontend/tests/home-card-contract.mjs`、`home-responsive.mjs`、`home-visual-overlay.mjs`、`home-layout-persistence.mjs`。

## STUDY.UI

- 稳定导出：`frontend/src/design-system/index.js`，应用通过 `@study-ui` 使用公共组件。
- 依赖方向：`Foundations -> Atoms -> Molecules -> Organisms -> Widgets -> Pages`。
- 本轮新增：`UiPillButton`、`UiCompactHeader`、`UiInsetSurface`；`UiButton`、`UiBadge`、`UiProgress` 增加首页需要的紧凑状态。
- Storybook：按设计语言、通用、导航、数据录入、数据展示、反馈、布局、仪表盘组件、完整范例九类组织；原子层级写在组件文档中。
- 边界：当前完成的是正式首页及其九张卡片，不代表其他页面的 Toast、Modal/Drawer、表单和全部按钮已经统一。
- 2026-08-03 验证：前端单元测试 `43` 个文件、`92` 项全部通过；Storybook 和生产构建通过；四组首页回归通过；完整首页范例无障碍检查 `0` 项违规。

## SH.WORKBENCH

- 页面路由：`/workbench`，路由名 `workbench`；模块通过 `?tab=overview|tasks|approvals|versions|environment|roadmap` 选择。
- 前端面板：`OverviewPanel.vue`、`CasesPanel.vue`、`ApprovalsPanel.vue`、`VersionsPanel.vue`、`EnvironmentPanel.vue`、`RoadmapPanel.vue`。
- 前端服务：`services/workbench.js`、`workbenchOverview.js`、`workbenchApprovals.js`、`workbenchVersions.js`、`workbenchEnvironment.js`。
- 后端接口：`/workbench/overview`、`/workbench/cases`、`/workbench/approvals`、`/workbench/versions`、`/workbench/test-versions`、`/workbench/environment`、`/workbench/roadmap` 及审批动作接口。
- 约束：审批只有 `pending` 可处理；审批通过不等于执行或发布；测试版本必须通过测试后才能提交发布审批；环境返回受控脱敏字段；无规划时返回缺失状态而不伪造内容。
- WB-14 验证：后端全量 `76 passed`；Vite build 通过；路由唯一性、前端 `/workbench/*` API 路径、Workbench 六面板实际动态渲染和桌面无横向溢出已检查。浏览器 API 数据态复测因本地后端重启实例未能稳定监听，记录于项目状态。
