## 当前部署架构

```
开发模式（npm run dev）
  前端 5173 ──Vite 代理──→ 后端 8741
  apiBase = '/api'

生产预览（vite preview --port 5173）
  前端 5173 ──直连──→ 后端 8741
  apiBase = 'http://localhost:8741'  ⚠ 硬编码，见 ISS-021

生产部署（目标状态）
  Nginx / Caddy ──静态文件──→ dist/
                ──API 转发──→ uvicorn 8741

```

## 当前技术栈
- 后端：Python 3.12 + FastAPI + uvicorn
- 前端：Vue 3 + Vite
- 数据库：SQLite（单文件，可移植）
- 向量库：ChromaDB（本地目录，可移植）
- 部署方式：Windows 本地后台启动 / Docker（待完善）
