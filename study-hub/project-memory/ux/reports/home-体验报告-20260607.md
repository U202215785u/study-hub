## 3. 发现的问题

### P2-001：移动端 390px 顶部导航文字截断

- **级别**：P2
- **描述**：390px 视口下，顶部导航栏"学习中枢"标题和右侧导航项（知识库、Wiki、学习、工作流等）文字严重截断，"学习"显示为"学"，"知识库"显示为"知"等。
- **截图**：`home-p3-mobile.png`
- **建议**：移动端隐藏部分导航项或使用折叠菜单。

### P2-002：知识库操作按钮在移动端换行拥挤

- **级别**：P2
- **描述**：390px 视口下，知识库区域的上传文档/搜索知识库/粘贴 Claude 对话/打开收件箱按钮排成了两行，布局拥挤。
- **截图**：`home-p3-mobile.png`
- **建议**：移动端改为图标按钮或折叠菜单。

### P2-003：复制操作反馈待确认

- **级别**：P2
- **描述**：点击文档"复制"按钮后，在浏览器自动化环境中未观察到 Toast 反馈。不确定是剪贴板 API 限制还是前端未显示反馈。
- **建议**：在真实浏览器中复测，确认复制成功/失败是否有 Toast。

### P3-001：常用网站和 AI 启动器添加流程未走查

- **级别**：P3
- **描述**：本次走查未测试添加新常用网站和添加新 AI 启动器的完整流程。
- **建议**：后续补充测试。

### P3-002：解析任务提交和完成流程未走查
