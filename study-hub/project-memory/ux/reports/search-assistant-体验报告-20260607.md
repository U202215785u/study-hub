## 3. 问题分级

### 3.1 P1（核心路径阻断）

**无 P1 阻断。** 所有核心路径均可用。

### 3.2 P2（明显体验问题）

| 编号 | 问题 | 描述 | 影响 |
|------|------|------|------|
| UX-SA-001 | 固定状态默认值矛盾 | `loadState()` 中 `app.pinned = s.pinned !== false` 导致无存储时默认固定，与代码注释"默认不固定"矛盾 | 用户首次使用面板即固定，与预期可拖拽不符 |
| UX-SA-002 | AI 分析折叠交互不稳定 | 点击 `.sh-ai-header` 通过事件委托触发折叠，但在 Shadow DOM 内可能不响应 | AI 分析区域无法折叠/展开 |
| UX-SA-003 | 浮窗位置与描述不符 | 任务卡和 PRD 描述为"右下角"，实际代码是 `top: 72px; right: 16px`（右上角） | 用户期望与实际位置不符 |
| UX-SA-004 | 无真实 AI 分析接入 | AI 分析区域为占位文案，用户可能困惑 | 体验不完整（本轮不做，已记录在任务卡） |
| UX-SA-005 | 中文 Unicode 转义 | 代码中大量使用 `\uXXXX` 转义中文，可读性差 | 维护成本高（本轮不做，已记录） |

### 3.3 P3（增强/扩展）

| 编号 | 问题 | 描述 |
|------|------|------|
| UX-SA-006 | 场景规则静态 JSON | 无后端 API 支持动态更新 |
| UX-SA-007 | 无深色模式检测 | 未检测 Bing 主题自动切换 |
| UX-SA-008 | 无移动端适配 | 窄屏未变为底部抽屉 |
