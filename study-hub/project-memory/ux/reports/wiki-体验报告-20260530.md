## 五、技术限制说明

本次走查遇到以下技术限制：

1. **Vue 事件监听机制**: 编辑按钮使用 Vue 的 `@click` 事件绑定，Claw 的 `el.click()` 和 `dispatchEvent` 无法触发。需要进一步研究如何通过 WebBridge 正确触发 Vue 组件事件。
2. **中文 URL 编码**: 文章 slug 包含中文，URL 编码后导致导航问题。
3. **截图工具缺失**: `jq` 命令不可用，无法使用 screenshot.sh 脚本；直接调用 screenshot API 因 base64 数据过大导致超时。
4. **弹窗检测**: Vue 的 v-if 控制的弹窗在 DOM 中不存在，无法预先检查。
