# Home 体验测试脚本

最后更新：2026-06-07
对应任务卡：`study-hub/project-memory/ux/plans/2026-06-07-home-entry-feedback.md`

---

## 测试环境

- 前端：http://localhost:5173/
- 后端：http://localhost:8741
- 视口：1280x900（桌面）、768x1024（平板）、390x844（手机）

---

## 路径 1：搜索与启动

### 1.1 搜索入口可发现性
- [ ] 打开 `/`，搜索框是否在首屏明显位置。
- [ ] 搜索模式切换（AI推荐/知识库/全网/命令）是否可理解。
- [ ] 分类筛选下拉框是否正常工作。

### 1.2 常用网站
- [ ] 常用网站是否在首屏可见。
- [ ] 点击常用网站是否正常跳转外部链接。
- [ ] 删除常用网站：点击 × 后是否有 confirm 确认，确认后是否从列表移除。
- [ ] 删除按钮是否比主点击区域小，不会误触。
- [ ] 添加新常用网站是否正常工作。

### 1.3 AI 启动器
- [ ] AI 启动器是否在首屏可见。
- [ ] 点击 AI 启动器是否正常跳转。
- [ ] 删除 AI 启动器：点击 × 后是否有 confirm 确认。
- [ ] 添加新 AI 启动器是否正常工作。

---

## 路径 2：最近文档操作

### 2.1 最近文档列表
- [ ] 最近文档是否在首屏可见。
- [ ] 切换排序（最新/最早/标题 A-Z/Z-A）是否正常工作。
- [ ] 无最近文档时是否有空状态引导。

### 2.2 文档操作
- [ ] 点击文档是否能预览（不打开空白弹窗）。
- [ ] 复制文档内容是否有成功反馈。
- [ ] 删除文档是否有 confirm 确认，确认后列表是否刷新。
- [ ] ASR 重识是否有反馈。

### 2.3 上传与导入
- [ ] 文件上传是否有进度/成功反馈。
- [ ] 粘贴 Claude 对话存入是否有反馈。
- [ ] 打开收件箱是否正常跳转。

---

## 路径 3：自动化解析与队列

### 3.1 解析入口
- [ ] 抖音/B站/小红书解析卡片是否在首屏可见。
- [ ] 输入链接后点击解析是否有任务创建反馈。
- [ ] 批量导入是否正常工作。
- [ ] 重复点击提交是否有防重复机制。

### 3.2 解析队列
- [ ] 点击解析队列入口是否能打开抽屉。
- [ ] 队列中运行中/完成/失败任务是否有明确区分。
- [ ] 失败任务是否有原因和重试入口。
- [ ] 清除已完成任务是否正常工作。
- [ ] 刷新队列是否正常工作。

---

## 路径 4：系统状态与恢复

### 4.1 系统状态
- [ ] 系统状态区域是否在首屏可见。
- [ ] 后端正常时状态显示是否正确。

### 4.2 错误场景
- [ ] 后端不可用时是否有错误提示（不空白）。
- [ ] API 返回 error 时是否有可理解提示。
- [ ] 文档不存在时是否有错误提示（不打开空白弹窗）。

---

## 边界测试

### 5.1 空状态
- [ ] 无常用网站时的展示。
- [ ] 无 AI 启动器时的展示。
- [ ] 无最近文档时的展示。
- [ ] 无队列任务时的展示。

### 5.2 移动端
- [ ] 390px 视口下卡片不溢出。
- [ ] 操作按钮可点击。
- [ ] 搜索框可用。

### 5.3 性能
- [ ] 页面加载时间 < 3s。
- [ ] 队列抽屉打开流畅。
- [ ] 文档弹窗打开流畅。
