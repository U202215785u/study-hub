# Search Assistant 体验测试脚本

> 目标：在真实浏览器（Bing 搜索页）中验证 Study Hub 搜索助手浮窗的四条核心路径。
> 测试方式：Playwright WebBridge 注入 mock 扩展脚本，模拟 content script 行为。
> 前置条件：Bing 搜索页可访问。

---

## 路径 1：搜索触发与场景匹配

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1.1 | 打开 Bing.com，搜索「抠图工具」 | 浮窗出现在页面右下角 |
| 1.2 | 观察浮窗标题 | 显示场景图标 + 场景名称 |
| 1.3 | 确认当前场景 | 「工具查找」场景（关键词匹配） |
| 1.4 | 搜索「React API 文档」 | 场景切换为「技术文档」 |
| 1.5 | 搜索「耳机推荐」 | 场景切换为「产品测评」 |
| 1.6 | 搜索「的」（无意义单字） | 浮窗出现，显示默认场景「工具查找」 |
| 1.7 | 直接打开 bing.com（无 q 参数） | 浮窗不出现 |

**通过标准**：所有场景匹配准确，无匹配时显示默认场景，非搜索页不出现。

---

## 路径 2：来源筛选与应用

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 2.1 | 在「工具查找」场景下查看来源列表 | 显示 GitHub、Product Hunt、官网 |
| 2.2 | 勾选「GitHub」来源 | 复选框变为选中状态 |
| 2.3 | 点击「应用筛选并搜索」 | URL 改写为 `q=... site:github.com`，页面刷新 |
| 2.4 | 刷新后观察筛选状态 | GitHub 仍被勾选（sessionStorage 恢复） |
| 2.5 | 点击「恢复默认」 | 所有勾选清空 |
| 2.6 | 不勾选任何来源，点击「应用筛选」 | 提示「请先勾选至少一个来源」 |

**通过标准**：来源勾选/取消有即时反馈，应用筛选改写 URL 正确，筛选状态保持。

---

## 路径 3：面板交互

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 3.1 | 按住标题栏拖拽面板到左下角 | 面板跟随鼠标，松开后停留 |
| 3.2 | 点击固定按钮（📌） | 面板不可拖拽，位置固定 |
| 3.3 | 再次点击固定按钮 | 面板恢复可拖拽 |
| 3.4 | 点击关闭按钮（✕） | 面板消失，右下角出现小圆点（✨） |
| 3.5 | 点击小圆点 | 面板恢复，场景和状态保持 |
| 3.6 | 连续关闭→恢复→关闭 | 不创建重复面板/圆点 |
| 3.7 | 按 ESC 键 | 面板关闭（如未关闭） |
| 3.8 | 点击收起按钮 | 面板宽度收缩为 60px，仅显示图标 |
| 3.9 | 再次点击展开 | 面板恢复正常宽度 |

**通过标准**：拖拽流畅，固定/解除固定切换正常，关闭/恢复不重复，收起/展开正常。

---

## 路径 4：AI 分析与场景切换

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 4.1 | 观察 AI 分析区域 | 默认显示引导文案：「勾选来源并点击"应用筛选"，AI 将分析搜索结果」 |
| 4.2 | 点击 AI 分析标题栏 | 区域折叠，内容隐藏 |
| 4.3 | 再次点击 | 区域展开 |
| 4.4 | 点击场景标签切换到「教程学习」 | 来源列表和推荐内容同步更新 |
| 4.5 | 切换到「找官网」 | 来源变为官网/GitHub/Product Hunt |
| 4.6 | 搜索新关键词 | 场景重新自动匹配，不继承手动切换的场景 |

**通过标准**：AI 区域有引导文案，可折叠/展开，场景切换后内容同步更新，新搜索自动匹配。

## 边界测试

| 编号 | 场景 | 操作 | 预期 |
|------|------|------|------|
| B-01 | 普通搜索 | 搜「UE5 教程」 | 浮窗出现，场景匹配「教程学习」 |
| B-02 | 英文搜索 | 搜「how to learn react」 | 浮窗出现，场景匹配「教程学习」 |
| B-03 | 单字搜索 | 搜「的」 | 浮窗出现，默认场景不空白 |
| B-04 | 空搜索 | 打开 bing.com 无 q 参数 | 浮窗不出现 |
| B-05 | 非 Bing 页面 | 打开 baidu.com | 浮窗不出现 |
| B-06 | 拖拽到边缘 | 拖面板到屏幕边缘 | 面板不超出视口 |
| B-07 | 快速开关 | 连续点关闭→恢复→关闭 | 不创建重复面板 |
| B-08 | 筛选后刷新 | 应用筛选 → F5 刷新 | 筛选状态保持 |
| B-09 | 新搜索 | 筛选后 → 搜新词 | 新搜索不继承旧筛选 |
