## 测试环境

- 前端：http://localhost:5173/
- 后端：http://localhost:8741
- 视口：1280x900（桌面）、768x1024（平板）、390x844（手机）

---

## 路径 1：单链接解析

### 1.1 提交入口
- [ ] 打开 Home，自动化解析卡片是否首屏可见。
- [ ] 抖音摘要/B站解析/小红书解析三个入口是否清晰。
- [ ] 输入框 placeholder 是否可理解。

### 1.2 单链接提交
- [ ] 粘贴有效链接，点击"开始解析"。
- [ ] 提交后是否有立即反馈（按钮状态变化/Toast）。
- [ ] 卡片内是否显示步骤进度条（extract_meta / summarize / import）。
- [ ] 步骤颜色是否正确区分（进行中/完成/失败）。

### 1.3 队列查看
- [ ] 点击"解析队列"打开抽屉。
- [ ] 统计看板（待处理/进行中/已完成/失败）是否正确。
- [ ] 任务列表中状态徽章是否清晰。
- [ ] 步骤颜色条是否正确。
- [ ] 已完成任务是否可点击跳转文档。

### 1.4 结果打开
- [ ] 任务完成后，文档列表是否刷新。
- [ ] 生成文档是否可正常打开预览。

---

## 路径 2：批量解析

### 2.1 批量提交
- [ ] 展开"批量导入" textarea。
- [ ] 粘贴多行链接。
- [ ] 点击"开始解析"。
- [ ] 是否创建多个任务。
- [ ] 重复链接是否去重。

### 2.2 队列统计
- [ ] 队列抽屉统计数字是否正确（总数/进行中/已完成/失败）。
- [ ] 部分成功/部分失败是否可区分。

---

## 路径 3：重新解析

### 3.1 重新解析流程
- [ ] 打开已有解析文档。
- [ ] 点击重新解析（如有）。
- [ ] 旧文档是否保留。
- [ ] 新任务是否出现在队列。
- [ ] 新任务成功后旧文档是否被替换。
- [ ] 新任务失败时旧文档是否仍可用。

---

## 路径 4：失败恢复

### 4.1 错误场景
- [ ] 提交空链接：是否不创建任务，有提示。
- [ ] 提交无效链接：错误文案是否可理解。
- [ ] API Key 无效：是否有专门提示和重试入口。
- [ ] 下载返回 HTML：是否有"链接已过期"类提示。

### 4.2 错误信息质量
- [ ] 错误文案不是裸异常堆栈。
- [ ] 用户知道是否可重试。
- [ ] 用户知道是否需要换链接或补依赖。

---

## 边界测试

| 场景 | 操作 | 预期 |
|---|---|---|
| 空输入 | 不填链接直接提交 | 不创建任务，提示输入 |
| 无效链接 | 提交 "not-a-link" | 提示格式错误或下载失败 |
| 重复链接 | 连续提交同一链接 | 去重或提示重复 |
| 队列空 | 打开抽屉 | "暂无任务" |
| 移动端 | 390px 打开抽屉 | 抽屉宽度适配，内容不溢出 |
| 清除已完成 | 点击"清除已完成" | 已完成的任务从列表移除 |
| 手动刷新 | 点击"刷新" | 列表更新，无闪烁 |
