## 测试环境

- 前端：http://localhost:5173/journal
- 后端：http://localhost:8741
- 视口：1280x900（桌面）、768x1024（平板）、390x844（手机）

---

## 路径 1：写今日日记

### 1.1 进入与默认状态
- [ ] 进入 `/journal`，默认选中今天。
- [ ] 日历今天日期有高亮或视觉区分。
- [ ] 时光轴"今天"有视觉区分（如"今天"徽章）。

### 1.2 写日记
- [ ] 选择心情 → 有即时视觉反馈（选中高亮）。
- [ ] 输入天气 → 胶囊样式正常。
- [ ] 输入地点 → 胶囊样式正常。
- [ ] 选择贴纸 → 有弹跳动画。
- [ ] 输入正文 → placeholder 温暖不压迫，2 倍行距正常。
- [ ] 添加标签 → 回车添加，带 × 可移除。
- [ ] 从标签云点击添加标签 → 正常追加。

### 1.3 保存
- [ ] 点击保存 → 按钮有 loading 态（"保存中…"）。
- [ ] 保存成功 → "还未保存"变为"上次保存 HH:MM"。
- [ ] 保存成功后日历今天出现小圆点。
- [ ] 保存成功后时光轴出现新条目。
- [ ] 同一天多次保存 → 自动合并，不创建重复条目。

### 1.4 空内容保存
- [ ] 不写正文直接保存 → 允许保存，不报错。

---

## 路径 2：查看历史与编辑

### 2.1 日历导航
- [ ] 日历有日记的日期显示小圆点。
- [ ] 点击有圆点的日期 → 加载该天日记。
- [ ] 点击无圆点的日期 → 加载空白模板。
- [ ] 日历支持 ‹ › 年月切换。

### 2.2 时光轴导航
- [ ] 时光轴显示当月日记列表（日期+心情+预览）。
- [ ] 点击时光轴条目 → 加载该天日记。
- [ ] 当月超过 15 条时是否截断。

### 2.3 编辑与删除
- [ ] 加载已有日记 → 修改内容 → 保存 → 更新不创建重复。
- [ ] 点击删除 → 有 confirm 确认。
- [ ] 确认删除 → 条目删除，日历圆点消失，时光轴刷新。
- [ ] 取消删除 → 数据仍保留。

---

## 路径 3：统计与回顾

### 3.1 统计
- [ ] 左侧顶部显示总天数和连续天数。
- [ ] 连续天数计算准确（今天/昨天/前天边界）。
- [ ] 右侧心情分布进度条百分比正确。

### 3.2 随机回顾
- [ ] 随机回顾区域显示一篇旧日记预览。
- [ ] 点击"换一篇" → 刷新随机结果。
- [ ] 点击随机回顾卡片 → 跳转到那篇日记。
- [ ] 无日记时显示温和空状态。

---

## 路径 4：边界与错误

### 4.1 数据安全
- [ ] 写了内容 → 不保存 → 点击另一个日期 → 是否提示未保存或自动暂存。
- [ ] 快速连点保存 3 次 → 按钮有禁用态，不创建重复。
- [ ] 保存失败时提示 → 不是裸 alert，用户可理解。

### 4.2 空状态
- [ ] 无日记时进入 → 日历无圆点，时光轴显示"这个月还没有写字"。
- [ ] 心情全为同一种 → 心情分布一个占 100%，其他不显示。

### 4.3 移动端
- [ ] 390px 视口下三栏布局是否可用。
- [ ] 是否有横向溢出。
