## 核心路径 1：浏览 Wiki 主页

**用户目标**: 快速找到想看的文章，了解知识库结构

| 步骤 | 操作 | 预期体验 | 检查点（尼尔森原则） |
|------|------|---------|-------------------|
| 1.1 | 访问 http://localhost:5173/wiki | 页面秒开，左侧树形索引清晰可见 | #1 系统状态可见性、#8 美观与简洁 |
| 1.2 | 观察左侧边栏 | 分类层级关系直观，文章列表可点击 | #6 识别而非回忆、#4 一致性 |
| 1.3 | 点击一篇文章 | 右侧/主区域平滑加载文章内容，有封面图展示 | #1 系统状态可见性、#2 系统与现实匹配 |
| 1.4 | 滚动阅读 | 排版舒适，标题层级清晰，代码块/引用样式统一 | #8 美观与简洁、#4 一致性 |

**关键检查点**:
- [ ] 空状态：如果没有文章，是否有引导创建文案？
- [ ] 树形索引层级超过 3 层时是否还能清晰展示？
- [ ] 文章加载时是否有 loading 状态？
- [ ] 封面图加载失败时的降级处理？

## 核心路径 2：创建 Wiki 页面（含封面图）

**用户目标**: 创建一篇带封面图的新文章

| 步骤 | 操作 | 预期体验 | 检查点（尼尔森原则） |
|------|------|---------|-------------------|
| 2.1 | 点击"新建"或 ✏️ 编辑按钮 | 弹出编辑弹窗，表单字段清晰 | #1 系统状态可见性、#6 识别而非回忆 |
| 2.2 | 填写标题 | 有字数提示/限制，实时校验 | #5 防错 |
| 2.3 | 选择分类 | 下拉选择或输入，有已有分类提示 | #6 识别而非回忆 |
| 2.4 | 选择封面图 | 6 张内置图可视化展示，点击即选，有选中状态 | #6 识别而非回忆、#1 系统状态可见性 |
| 2.5 | 或使用 AI 生成封面图 | 点击 ✨ AI 生成，有 loading 状态，生成后自动选中 | #1 系统状态可见性、#7 灵活性与效率 |
| 2.6 | 填写 Markdown 内容 | 编辑器有工具栏，预览实时同步 | #6 识别而非回忆、#2 系统与现实匹配 |
| 2.7 | 点击保存 | 有 saving 状态 → 成功提示 → 自动刷新列表和文章 | #1 系统状态可见性、#3 用户控制与自由 |

**关键检查点**:
- [ ] 空标题保存时是否有即时错误提示？
- [ ] AI 生成封面图失败时（网络/余额不足）是否有友好提示？
- [ ] 保存过程中能否取消？
- [ ] 保存成功后是否自动跳转到新文章？
- [ ] 如果标题修改导致 slug 变化，URL 是否自动更新？

## 核心路径 3：编辑现有页面（Inline 编辑）

**用户目标**: 快速修改一篇文章的标题/封面/内容

| 步骤 | 操作 | 预期体验 | 检查点（尼尔森原则） |
|------|------|---------|-------------------|
| 3.1 | 在阅读页面点击 ✏️ 编辑按钮 | 弹窗出现，预填充当前内容 | #6 识别而非回忆 |
| 3.2 | 修改标题 | 输入框已有原文，修改方便 | #7 灵活性与效率 |

**关键检查点**:

## 核心路径 4：使用右侧预览面板（内联阅读）

**用户目标**: 在阅读时快速查看相关文章，不离开当前页面

| 步骤 | 操作 | 预期体验 | 检查点（尼尔森原则） |
|------|------|---------|-------------------|
| 4.1 | 在一篇文章中点击 wikilink | 右侧弹出 420px 预览面板，有滑入动画 | #1 系统状态可见性、#7 灵活性与效率 |
| 4.2 | 在预览面板中继续点击链接 | 面板内容切换，有面包屑或返回方式 | #3 用户控制与自由、#6 识别而非回忆 |
| 4.3 | 点击"切换为主文章" | 主阅读区平滑切换到该文章 | #3 用户控制与自由 |
| 4.4 | 点击关闭或遮罩层 | 面板平滑关闭，回到原文章 | #3 用户控制与自由 |

**关键检查点**:
- [ ] 预览面板加载失败时（如目标文章不存在）是否有错误提示？
- [ ] 面板内是否可以滚动独立？
- [ ] 移动端/窄屏下面板行为是否合理？

## 边缘场景（Claw 自主探索）

| 场景 | 操作 | 预期体验 |
|------|------|---------|
| 空数据 | 首次使用，没有任何 Wiki 文章 | 有引导文案"暂无文章，点击创建"或空状态插图 |
| 超长标题 | 输入 200 字标题 | 有字数限制提示，超出后阻止输入或截断提示 |
| 快速连续保存 | 快速点击保存 5 次 | 有防抖机制，不会创建重复文章 |
| 网络中断 | 编辑完成后断网，点击保存 | 有网络错误提示，内容不丢失，可重试 |
| 反向操作 | 编辑后点击取消/关闭弹窗 | 有未保存确认提示（如内容有变更） |
| 封面图 404 | 使用自定义 URL，图片不存在 | 有降级处理（默认封面或占位图） |
| AI 生成超时 | AI 生成封面图超过 30 秒 | 有超时提示，可取消或重试 |
| 大量文章 | 左侧索引有 50+ 文章 | 列表可滚动，有搜索/筛选功能 |
| 深色模式 | 切换到暗黑主题 | 所有元素颜色适配，无刺眼对比 |
| 移动端适配 | 窗口宽度 < 768px | 布局自适应，左侧索引可收起 |

## 评估维度权重

```yaml
权重配置:
  1. 系统状态可见性: 1.3    # Wiki 操作反馈特别重要（保存、加载、AI生成）
  2. 系统与现实世界匹配: 1.0
  3. 用户控制与自由: 1.2     # 编辑操作需要撤销/取消能力
  4. 一致性与标准: 1.1       # 编辑器、弹窗、按钮样式需统一
  5. 防错: 1.2              # 防止误保存、误关闭
  6. 识别而非回忆: 1.0
  7. 灵活性与效率: 1.1       # 内联编辑、预览面板提升效率
  8. 美观与简洁: 1.2         # Markdown 阅读体验是核心
  9. 容错: 1.1              # 网络错误、图片 404 处理
  10. 帮助文档: 0.7          # Wiki 模块相对直观，帮助次要
```
