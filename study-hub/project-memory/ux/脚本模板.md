## 评估维度权重

> 根据模块特性，调整十原则的权重（默认等权）

```yaml
权重配置:
  1. 系统状态可见性: 1.2  # 该模块操作反馈特别重要
  2. 系统与现实世界匹配: 1.0
  3. 用户控制与自由: 1.2  # 该模块操作不可逆，需要强调
  4. 一致性与标准: 1.0
  5. 防错: 1.2
  6. 识别而非回忆: 1.0
  7. 灵活性与效率: 0.8  # 该模块使用频率低，效率次要
  8. 美观与简洁: 1.0
  9. 容错: 1.2
  10. 帮助文档: 0.8  # 该模块简单，不需要帮助
```
