## 1. 任务卡定位

本卡是高频主路径第五张（最后一张）任务卡。

Wiki、Home、Automation、Journal 已完成首轮走查，Journal P1 已修复。Search Assistant 是五个高频模块中最特殊的一个——它不在 Study Hub 自己的页面上运行，而是以浏览器扩展的形式注入到 Bing 搜索结果页。这意味着：

- 测试必须在真实浏览器中进行（Bing.com）。
- 依赖 Chrome 扩展的加载和 content script 注入机制。
- 场景匹配、来源筛选、AI 分析、面板交互都发生在第三方页面上。

本卡目标：

```text
在 Bing 搜索任意关键词
  -> 浮窗自动出现
  -> 场景自动匹配
  -> 来源筛选/应用筛选
  -> AI 分析区域可折叠
  -> 拖拽/固定/关闭/恢复
  -> 刷新页面状态保持
```

本卡不做 AI 分析后端的真实接入，不做新场景规则设计，优先验证浮窗的基础交互和场景匹配是否在真实浏览器中正常。

## 3. 核心用户路径

### 路径 1：搜索触发与场景匹配

用户目标：在 Bing 搜索 → 浮窗出现 → 识别搜索意图 → 匹配场景。

步骤：

1. 用户在浏览器打开 Bing.com。
2. 用户搜索关键词（如"UE5 教程"、"抠图工具"、"耳机推荐"）。
3. 搜索结果页加载完成。
4. 浮窗出现在页面右下角。
5. 浮窗自动匹配场景（如"UE5 教程"→ 教程学习）。
6. 浮窗显示场景图标、名称、推荐来源、小贴士。

成功标准：

- 浮窗在任意 Bing 搜索页出现。
- 场景匹配准确（至少命中 3 个不同场景）。
- 无场景匹配时显示默认场景（工具查找）而非空白。
- 页面刷新后浮窗仍出现。
- 浮窗不遮挡 Bing 核心搜索结果（右下角位置）。

### 路径 2：来源筛选与应用

用户目标：按来源过滤搜索结果 → 应用筛选 → 查看过滤后的结果。

步骤：

1. 浮窗显示当前场景的来源列表。
2. 每个来源有图标、名称、命中数。
3. 用户勾选/取消来源。
4. 用户点击"应用筛选"。
5. 页面 URL 添加 site: 限定词并刷新。
6. 刷新后筛选状态保持。

成功标准：

- 来源列表和场景匹配。
- 勾选/取消有即时反馈。
- "应用筛选"改写 URL 正确（site:bilibili.com 格式）。
- 筛选后 Bing 搜索结果减少为仅该来源。
- 筛选状态在页面刷新后保持（chrome.storage）。

### 路径 3：面板交互

用户目标：拖拽面板、固定面板、关闭面板、恢复面板——全部可控。

步骤：

1. 用户按住标题栏拖动面板到任意位置。
2. 面板跟随鼠标移动，松开后停留在新位置。
3. 用户点击固定按钮，面板不再可拖。
4. 用户再次点击解除固定，面板恢复可拖。
5. 用户点击关闭按钮，面板消失。
6. 页面右下角出现一个小圆点。
7. 用户点击小圆点，面板恢复。

成功标准：

- 拖拽流畅，松开后面板留在原位。
- 固定/解除固定切换有视觉反馈。
- 关闭后面板 DOM 不泄漏（只有一个 shadow host）。
- 小圆点可见但不碍眼。
- 小圆点点击后面板恢复，位置和状态保持。
- 关闭 + 恢复不会创建重复面板。

### 路径 4：AI 分析与场景切换

用户目标：了解 AI 分析区域的作用，在场景间自由切换。

步骤：

1. 用户在面板中找到 AI 分析区域。
2. 默认显示引导文案（非空白）。
3. 用户点击 AI 分析标题栏 → 展开/收起。
4. 用户点击场景标签切换到另一个场景。
5. 场景切换后来源列表和推荐内容同步更新。

成功标准：

- AI 分析区域默认有引导文案，解释当前占位状态。
- 展开/收起有视觉过渡。
- 场景标签手动切换不会覆盖场景自动匹配（下次新搜索仍自动匹配）。
- 切换场景后来源和推荐正确更新。
- 所有 5 个场景都有推荐内容，无空推荐。

## 5. 体验设计要求

### 5.1 浮窗的存在感

浮窗是"帮手"不是"广告"：

- 位置：右下角，不遮挡搜索结果。
- 宽度：360px，不挤压 Bing 主内容区。
- 默认不固定，可拖拽到用户喜欢的位置。
- 关闭后小圆点保持低调（半透明、小尺寸）。
- 不与 Bing 自己的侧边栏（Copilot 等）冲突。

### 5.2 场景匹配的准确感

用户搜任何东西，浮窗都能给一个合理的场景：

- 命中的场景要"对得上"搜索词。
- 未命中时默认"工具查找"而不是空白。
- 用户应该感觉"它懂我要找什么"。

### 5.3 来源筛选的有用感

筛选不只是装饰，要真的能过滤：

- 点击来源能看到该域名的命中数。
- "应用筛选"后 URL 改写正确，搜索结果真的变少了。
- 筛选状态保持，不会刷新后就没了。

### 5.4 AI 分析的诚实感

因为 AI 分析是占位状态，不能让用户以为坏了：

- 引导文案诚实但温和："AI 分析即将接入，届时可以帮你总结搜索结果……"
- 区域默认收起，不抢注意力。
- 不要显示空白区域或报错。
