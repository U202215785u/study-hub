## 5. 设计方案

### 5.1 重复 h1 标题

目标：

- 阅读区只出现一个主标题。
- 如果后端内容已经以 `# title` 开头，前端不再重复注入。
- 如果后端内容没有一级标题，前端保留兜底标题。

验收：

- Wiki 主页阅读态不重复显示同一标题。
- WikiPage 独立页不重复显示同一标题。
- 没有一级标题的历史内容仍能显示标题。

### 5.2 元信息展示

建议方向：

```text
Title
[分类] [字数] [更新时间] [版本/来源]
[tag] [tag] [tag]
```

规则：

- 分类、字数、日期用轻量 chips。
- 标签单独一行或自动换行。
- 长标签截断或换行，不挤压操作按钮。
- 重要操作按钮不和元信息抢一行。

验收：

- 元信息在 1280px 不拥挤。
- 元信息在 768px 能换行。
- 元信息在 390px 不遮挡正文。

### 5.3 树形索引层级

建议方向：

```text
▾ AI 工具
  ├ 项目
  ├ Prompt
  └ 工作流
▾ 写作
  ├ 小红书
  └ 视频脚本
```

可选实现：

- 使用缩进 + folder/page 图标。
- 使用边线或层级线。
- 使用 disclosure caret 表示展开/收起。

验收：

- 用户能一眼区分父分类和子分类。
- 子层级不只依赖“·”。
- hover/active 状态清晰。

### 5.4 主题切换入口

建议方向：

- 移到 Wiki Header 的稳定位置。
- 使用图标 + tooltip 或短文本。
- 显示当前主题状态，如“纸面 / 牛皮纸 / 暗色”。

验收：

- 用户不用扫完整页面也能找到主题切换。
- 切换后状态持久化仍有效。
- 不遮挡正文和预览面板。

### 5.5 wikilink 空目标

建议方向：

当 wikilink 目标不存在时，右侧 Preview Dock 显示：

```text
页面还没有创建
[创建这个页面] [返回当前阅读]
```

规则：

- 不显示空白面板。
- 不让用户以为系统坏了。
- 如果新建入口已可复用，可跳转到新建弹窗并预填标题。

验收：

- 点击不存在的 wikilink 有明确反馈。
- 用户能继续阅读或创建页面。

## 6. 边界测试

| 场景 | 操作 | 预期 |
|---|---|---|
| 后端内容已有 h1 | 打开文章 | 不重复标题 |
| 后端内容无 h1 | 打开文章 | 前端显示兜底标题 |
| 标签很多 | 打开含 8+ 标签文章 | 标签换行，不遮挡按钮 |
| 分类很长 | 打开长分类文章 | chip 截断或换行 |
| 树形多层级 | 分类含 3 层路径 | 层级清晰 |
| 不存在 wikilink | 点击空目标链接 | 显示友好空状态 |
| 窄屏 390px | 打开 Wiki | 左栏/正文/预览有降级策略 |
| 主题切换 | 连续切换 3 次 | 状态正确且持久化 |
| 封面图坏链 | 设置错误封面 URL | 正文仍可读 |
