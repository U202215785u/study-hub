# Study Hub — 设计师对接文档

> 本文档面向 UI/UX 设计师，说明当前框架的结构、需要设计的范围、各模块的字段与状态，以及对接流程建议。
> 
> 原型文件：`study-hub-dashboard-style-refresh.html`（单文件 HTML 原型，含 14 个页面）

---

## 一、项目概述

Study Hub 是一个**个人学习管理中枢（Personal Learning OS）**，核心功能包括：

- **知识管理**：Wiki 知识库 + Knowledge Base 文档库
- **自动化采集**：从抖音/B站/小红书等自动提取内容
- **任务与时间管理**：DDL 日历 + 任务队列
- **AI 助手**：Second Self 对话式知识助手
- **创作工具**：Creator Hub 内容创作工作台
- **工作流**：Workflow / SOP 流程编排
- **手账与复盘**：Journal 每日学习记录
- **技能扩展**：Skill Market 插件市场

**当前状态**：前端框架已完成（HTML/CSS/JS 原型），需要设计师进行**视觉设计升级**和**交互细节打磨**。

---

## 二、设计范围总览

### ✅ 需要设计师输出的内容

| 类别 | 具体内容 | 优先级 |
|------|---------|--------|
| **设计系统 (Design System)** | 颜色、字体、间距、圆角、阴影、动效规范 | P0 |
| **图标体系 (Iconography)** | 所有功能图标、状态图标、空状态插画 | P0 |
| **页面视觉设计** | 14 个页面的高保真视觉稿 | P1 |
| **组件设计** | 卡片、按钮、输入框、弹窗、侧边栏等原子组件 | P0 |
| **交互状态** | Hover、Active、Disabled、Loading、Empty、Error | P1 |
| **响应式适配** | 桌面端 (1280px+) / 平板 / 移动端 | P2 |
| **空状态 & 异常状态** | 无数据、加载中、错误、权限不足等 | P2 |
| **动效规范** | 页面切换、卡片拖拽、弹窗、通知 toast | P2 |

### ❌ 不需要设计师做的

- 前端代码实现（已有 HTML/CSS/JS 原型）
- 业务逻辑设计（已有完整功能定义）
- 数据结构定义（已有字段说明，见下文）

## 三、页面清单（14 个页面）

**布局**：顶部导航 + 8×4 网格卡片区

| 卡片 | 尺寸 | 内容 |
|------|------|------|
| Queue / Progress | 2×2 | 自动化任务队列，含平台名称、分段进度条、步骤状态 |
| Today Focus / DDL | 2×2 | 时间线 + 今日任务进度条 + Tab 切换（Today Focus / DDL） |
| Queue Mini | 1×1 | 简化版队列，3 条任务摘要 |
| DDL Mini | 1×1 | 超期/今日统计数字 + 2 条 DDL |
| Wiki Recent | 1×1 | 最近 4 篇 Wiki 文档列表 |
| KB Stats | 1×1 | 文档数/标签数统计 + 本周新增 |
| Creator / Workflow | 2×2 | 4 个快捷入口（文章模板、数据报告、自动化流、快速笔记） |
| Journal / Review | 2×2 | 今日手账摘要 + 随机回顾 |

**需要设计师定义**：
- 卡片视觉风格（当前有浅色/深色两种变体）
- 拖拽时的视觉反馈（dragging / drag-over 状态）

## 五、设计系统需要定义的 Token

### 5.1 颜色 (Color)

当前框架已有一套 Dark SaaS 主题的 CSS Variables，设计师可以在此基础上优化：

```
--app-bg: #090a08          // 主背景
--app-shell: #121311       // 壳层背景
--surface-1: #1b1d1a       // 一级表面
--surface-2: #242722       // 二级表面
--surface-3: #30342d       // 三级表面
--text-strong: #f5f6ee     // 强调文字
--text: #d9dbd0            // 正文
--text-muted: #8f948a      // 弱化文字
--line: rgba(245,246,238,0.10)   // 分割线
--accent: #d7ff63          // 主强调色（荧光绿）
--accent-2: #8b73ff        // 次强调色（紫）
--accent-3: #ff8655        // 第三强调色（橙）
--success: #59f86d         // 成功
--warn: #f4e35c            // 警告
--danger: #ff6b6b          // 危险/错误
```

**需要设计师确认/优化**：
- [ ] 品牌主色是否保留荧光绿？还是更保守的配色？
- [ ] 是否需要浅色主题（Light Mode）？
- [ ] 各功能模块是否需要不同的主题色？
- [ ] 暗色主题下的对比度是否符合 WCAG 标准？

### 5.2 字体 (Typography)

当前使用：`'Inter', 'SF Pro Display', -apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui, sans-serif`

**需要设计师定义**：
- [ ] 中文字体选择（是否需要单独指定中文字体栈？）
- [ ] 字体大小层级（当前有 9px ~ 28px 多个尺寸，需要系统化）
- [ ] 行高规范
- [ ] 字重使用规范（400/500/600/700/800）

### 5.3 间距 (Spacing)

当前框架中的间距值较零散，需要设计师统一：

**需要设计师定义**：
- [ ] 基础间距单位（4px / 8px 网格系统？）
- [ ] 卡片内边距（当前有 12px / 16px / 18px / 20px / 24px）
- [ ] 卡片间距（当前 12px / 14px / 16px）
- [ ] 页面边距（当前 18px / 20px / 22px / 24px）

### 5.4 圆角 (Border Radius)

当前：
- 卡片：28px（较大）
- 按钮/标签/输入框：999px（全圆角）
- 小元素：8px / 12px / 16px

**需要设计师定义**：
- [ ] 圆角规范体系（大/中/小/全圆角的使用场景）

### 5.5 阴影 (Shadow)

当前卡片阴影：`0 18px 50px rgba(0,0,0,0.34), inset 0 1px 0 rgba(255,255,255,0.04)`

**需要设计师定义**：
- [ ] 阴影层级（ resting / hover / active / modal ）
- [ ] 是否使用彩色阴影（当前有 accent 色的发光效果）

### 5.6 动效 (Motion)

当前已有的动效：
- 卡片 Hover：translateY(-3px) + 阴影增强 + 边框高亮
- 卡片拖拽：opacity 0.66 + scale 0.985
- 按钮按下：translateY(1px) scale(0.98)
- 页面切换：无（当前是瞬间切换）

**需要设计师定义**：
- [ ] 页面切换过渡动画
- [ ] 卡片拖拽的完整动效流程
- [ ] 弹窗的进入/退出动画

## 八、设计师需要向产品经理/开发确认的问题

### 视觉方向
1. 品牌调性：当前是 Dark SaaS + 荧光绿强调色，是否保留？还是更偏向某类产品风格？
2. 目标用户：开发者/技术学习者？还是更广泛的学习者？
3. 是否有品牌 VI 或 Logo 需要遵循？

### 功能范围
4. 是否需要 Light Mode？（当前只有 Dark Mode）
5. 移动端是否支持？（当前是桌面优先，有响应式断点 1180px）
6. 是否有国际化需求？（当前是中文界面）

### 交互细节
7. 全局搜索是否支持 Command+K 快捷键唤起？
8. 卡片拖拽是否支持跨页面？（当前只在 Home 页面内拖拽）
9. 通知是否使用 Toast 弹窗还是仅红点标记？
10. 是否有加载状态/骨架屏的需求？

### 技术约束
11. 前端框架：当前是原生 HTML/CSS/JS，未来是否迁移到 React/Vue？
12. 图标方案：使用 SVG Sprite / Icon Font / 第三方库（如 Phosphor/Tabler）？
13. 图表库：当前热力图/柱状图是 CSS 实现，是否使用 Chart.js / D3.js？
