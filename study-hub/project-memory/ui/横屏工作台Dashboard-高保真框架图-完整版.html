Docker 网络模式详解
📅 06-07🏷️ docker✏️ 编辑中

概述

Docker 网络是容器化应用的核心基础设施之一。理解不同网络模式对于构建可扩展的微服务架构至关重要。

bridge 模式

bridge 是 Docker 默认网络模式，创建虚拟网桥 docker0 连接所有容器。

host 模式

host 模式直接使用宿主机网络栈，性能最优但隔离性最差。

overlay 模式

overlay 用于跨主机容器通信，是 Swarm 和 K8s 网络的基础。
