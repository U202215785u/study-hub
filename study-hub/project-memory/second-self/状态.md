#### 技术备忘（供重建参考）
- Three.js CDN 必须 ≤0.140（0.150+ 去掉 UMD 构建）
- DeepSeek API 密钥已配置在 `backend/ai_client.py`
- SQLite 连接需设置 `busy_timeout=10000`
- 社交媒体 MCP 当前支持 Bilibili / 小红书

- Markdown 渲染顺序：先 escape HTML，再 parse `**bold**`
- System Prompt 长度控制：HIGH 80-150字 / MEDIUM 40-80字 / LOW 20-40字
