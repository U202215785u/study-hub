## DEC-JR-001：参考《陪安东尼度过漫长岁月》风格设计 UI

**日期**：2026-06-06
**背景**：用户希望手账功能参考安东尼的写作风格
**决策**：
1. 无标点流水账风格 —— 不强制标点，placeholder 引导"像安东尼那样随便写"
2. 日期即标题 —— 大字号日期数字（如 06）作为页面视觉中心
3. 极简三元素 —— 天气、地点、心情，不加标题、分类等冗余字段
4. 碎碎念氛围 —— 仓耳今楷字体 + 2 倍行距 + 左侧装订线装饰
5. 不打卡不强迫 —— 无字数限制、无每日提醒、无强制连续记录

**影响文件**：
- `frontend/src/views/JournalView.vue`

## DEC-JR-002：一天一篇自动合并

**日期**：2026-06-06
**背景**：日记天然是一天一篇的
**决策**：数据库 date 字段加 UNIQUE 约束，POST 时同一天自动更新而非新建

**影响文件**：
- `backend/endpoints/journal.py`
- `backend/database.py`
