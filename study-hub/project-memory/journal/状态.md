### 数据库表

```sql
CREATE TABLE journal_entries (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    date TEXT NOT NULL UNIQUE,          -- 日期，一天一篇
    content TEXT NOT NULL DEFAULT '',   -- 正文
    mood TEXT DEFAULT 'neutral',        -- 心情
    tags TEXT DEFAULT '[]',             -- JSON 数组
    weather TEXT DEFAULT '',            -- 天气
    location TEXT DEFAULT '',           -- 地点
    sticker TEXT DEFAULT '',            -- 贴纸
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/journal/entries` | 列表，支持 year/month/tag/mood 筛选 |
| GET | `/api/journal/entries/{id}` | 单篇详情 |
| GET | `/api/journal/today` | 今天日记（无则返回空模板） |
| POST | `/api/journal/entries` | 创建/更新（同一天自动合并） |
| PUT | `/api/journal/entries/{id}` | 更新 |
| DELETE | `/api/journal/entries/{id}` | 删除 |
| GET | `/api/journal/stats` | 统计（total + streak） |
| GET | `/api/journal/tags` | 所有标签 |

## 设计风格

参考《陪安东尼度过漫长岁月》：
- **无标点流水账**：不强制标点，placeholder 引导"随便写点什么就好"
- **日期即标题**：大字号日期数字作为页面视觉中心
- **极简记录**：天气、地点、心情三个元素
- **碎碎念氛围**：仓耳今楷字体 + 2 倍行距 + 左侧装订线装饰
- **不打卡不强迫**：想起来就写，写多少算多少
