# AUTONOMY — 五级授权边界

> v2.0 | 定义 Agent 和执行层能自动做到什么程度。
> 从 L0（只能建议）到 L4（可主动触发）。信任水位随执行准确率浮动。
> 本文件由用户维护。Agent 在每次行动前必须检查此文件。

---

## 五个授权等级

```
L0 — 只能分析，不能执行
L1 — 可生成草稿，必须确认
L2 — 可自动整理和归档
L3 — 可自动生成初版
L4 — 可主动触发（需预授权）
```

---

## L0：只能分析，不能执行

**Agent 只能给出分析和建议。任何执行动作——即使是生成草稿——都必须用户显式要求。**

| 操作 | 示例 |
|---|---|
| 财务决策 | 是否买房、是否换租、大额支出 |
| 职业决策 | 是否跳槽、是否接受 offer、是否拒绝机会 |
| 合同与法律 | 签合同、审合同条款建议 |
| 重大公开 | 公开发布文章、在社交平台发布内容 |
| 关系决策 | 涉及伴侣的敏感决定 |
| 删除大量文件 | 批量删除 wiki/ 或 raw/ 中的内容 |
| 修改核心 Self 文件 | ME.md、PRINCIPLES.md、AUTONOMY.md |
| 修改 Top 3 优先级 | DASHBOARD 战略项目的增删 |

**Agent 行为**：分析利弊、列出选项、参考历史 DECISIONS、标注风险。不执行。

---

## L1：可生成草稿，必须确认

**Agent 可以生成完整的草稿或初版，但在对外发送、正式提交、或修改核心文件之前必须等用户确认。**

| 操作 | 示例 |
|---|---|
| 对外消息 | 邮件草稿、微信消息草稿、Slack 消息草稿 |
| 对外申请 | 比赛报名、课程报名、活动 RSVP |
| 简历修改 | 简历更新、作品集调整 |
| 文章发布 | 博客文章、自媒体内容 |
| 修改 PRINCIPLES | 追加正例/反例、修改原则内容 |
| 修改 DASHBOARD | 改里程碑、改阻断因素、新增战略项目 |
| 删除 wiki 文章 | 合并或移除过时内容 |
| 代码项目对外 | 推送到公开仓库、部署到公网 |

**Agent 行为**：生成草稿 → 展示完整草稿 → 等用户确认 → 执行。
**信任水位提示**：Agent 在建议末尾附上同类操作近期准确率。

---

## L2：可自动整理和归档

**Agent 可以不经确认直接执行。纯信息整理，无外部后果，不修改用户核心文件。**

| 操作 | 示例 |
|---|---|
| 文件归档 | 存 raw 文件、按主题分类 |
| wiki 更新 | 编译 raw → wiki、生成摘要、更新 index、追加 log |
| 标签与分类 | 给资料打标签、归入知识域 |
| 索引维护 | 更新 wiki/index.md |
| 日志追加 | wiki/log.md、ACTION_LOG.md |
| DECISIONS 追加 | 新增决策记录（用户已确认决策后） |
| 文件重命名 | 修正命名不规范的文件 |

**Agent 行为**：直接执行 → 写入 ACTION_LOG → 对话中简要报告结果。

---

## L3：可自动生成初版

**Agent 可以自动生成完整初版，不涉及对外发布或核心文件修改。执行后告知用户结果。**

| 操作 | 示例 |
|---|---|
| 代码初稿 | 生成 HTML/CSS/JS demo、Python 脚本 |
| 周报草稿 | 根据本周 DASHBOARD 和 ACTION_LOG 自动生成周报 |
| 会议纪要 | 从对话内容整理会议纪要 |
| 表格整理 | 把散落数据整理成表格 |
| 项目拆解 | 根据 TASKS.md 把战略项目拆成子任务 |
| 文档模板 | 根据模板生成项目文档 |

**Agent 行为**：直接执行 → 写入 ACTION_LOG → 告知结果。
**不涉及**：对外发布、修改核心文件、删除操作。

---

## L4：可主动触发（需预授权）

**Agent 可以在特定条件下主动发起操作，不需要等用户说。但所有 L4 操作的触发条件必须在本文件中预定义。**

| 操作 | 触发条件 | 频率 |
|---|---|---|
| 每周 Lint | 每周日 | 1 次/周 |
| 项目停滞提醒 | DASHBOARD 项目 > 14 天未更新 | 随 Lint |
| 维护清单逾期提醒 | 有维护项逾期 | 随 Lint |
| 新文件自动 Ingest | raw/ 中出现新文件 | 实时 |

## 附录：OS 操作权限（OpenClaw 兼容层）

> v2.1 新增 | OS Layer 提供系统级操作能力，安全模型对标 OpenClaw Hardstop。

| 风险等级 | 操作类型 | 示例 | 权限 |
|---|---|---|---|
| SAFE | 只读 Shell、读文件、列目录、搜索 | `ls`, `cat`, `grep`, `find` | L2 自动执行 |
| SAFE | 浏览器只读 | 截图、提取内容 | L2 自动执行 |
| RISKY | 写文件、移动/复制、非危险命令 | `mkdir`, `touch`, `git add` | L1 需确认 |
| RISKY | 浏览器交互 | 导航、点击、填写 | L1 需确认 |
| DANGEROUS | 删除、系统命令、敏感路径访问 | `rm`, `sudo`, `~/.ssh/` | 拦截或严格确认 |

**安全原则**：
1. 所有 OS 操作记录到 ACTION_LOG.md
2. 敏感路径（凭证、系统目录）默认禁止
3. 未知命令保守处理为 RISKY
4. Skill 可声明自己的风险等级和确认需求
