🧠 这个项目到底在干嘛？

一句话：把浏览器新标签页变成「学习操作系统」。

5 个核心模块：

  • 搜索框 —— 搜自己的知识库，或让 AI 基于你的资料回答
  • 常用网站 —— 一键打开 Claude、ChatGPT、DeepSeek 等
  • AI 启动器 —— Chrome 扩展自动采集你在这些网站的对话
  • 知识库 —— 上传 txt/md/pdf，AI 读懂内容，以后回答时引用
  • 每日复盘 —— 写学习笔记，AI 润色、关联知识库、生成周报
⚙️ 各模块是做什么的？出问题时看这里
模块作用坏了的症状
Frontend（前端）你看到的网页界面页面打不开、按钮没反应
Backend（后端）处理所有请求的「大脑」上传失败、搜索没结果
SQLite（数据库）存文档、分类、复盘内容数据丢失、记录找不到
ChromaDB（向量库）存 AI 能读懂的「语义」搜索不准、答非所问
Chrome 扩展自动采集 AI 对话对话没有回流到知识库
Inbox Watcher监听文件夹，自动导入新文件拖进 inbox 的文件没反应
🩺 遇到问题怎么自查？

症状 1：页面打不开

  • 看这个页面顶部的「系统状态」是不是绿灯
  • 如果不是，说明后端没启动，去命令行按 Ctrl + C 再重新启动

症状 2：上传文件失败

  • 看「知识库文档」数字有没有增加
  • 看日志区域有没有红色报错
  • 常见原因：文件名有特殊符号、文件太大（>50MB）

症状 3：AI 搜索答非所问

  • 看「数据大小」是不是 0 —— 如果是，说明向量库空了
  • 或者 embedding 模型加载失败（看日志）

症状 4：Chrome 扩展不采集

  • 打开 chrome://extensions，看扩展图标有没有变红
  • 点扩展图标，确认后端地址是 http://localhost:8741
🗂️ 数据都存在哪里？怎么备份？

所有数据都在 study-hub/backend/data/ 文件夹：

  • study_hub.db —— SQLite 数据库
  • chroma/ —— 向量库（AI 语义搜索用）
  • inbox/ —— 拖进去自动导入的文件

备份：直接复制整个 data/ 文件夹。恢复时复制回来即可。

🚀 怎么重启服务？

方法 1（推荐）：

  • 找到运行后端的黑色命令行窗口
  • 按 Ctrl + C 停止
  • 再运行启动命令

方法 2（如果找不到窗口）：

  • 任务管理器 → 找到 python.exe → 结束任务
  • 重新运行启动命令
