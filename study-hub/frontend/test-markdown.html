🔬 Markdown 样式对比测试

这是一级标题 (h1)

这是一段正文。如果样式生效，这段文字应该有 1.6 的行高，段落之间有 1em 的间距。Kami 的排版理念是让内容有呼吸感。

这是二级标题 (h2)

这是另一段正文。注意看标题和段落之间的间距——h1/h2 后面应该有更宽松的间距（1.8em），而 h3 后面间距更紧凑。

这是三级标题 (h3)

三级标题通常用于小节。如果生效，它的字号应该比 h2 小，但比正文大。

  • 列表项一
  • 列表项二
    • 嵌套列表项
  • 列表项三

这是一个引用块。如果生效，左边应该有 3px 的 accent 色边框，背景有淡淡的紫色渐变。

// 代码块
function hello() {
  return "world";
}

正文中的 inline code 应该有不同的背景色。

✅ 如果生效，你应该看到：

  • h1 标题是粉红色，字号很大，底部有粉红边框
  • 段落之间有清晰的间距，不拥挤
  • 列表项之间有 0.6em 的间距
  • 引用块左边有紫色竖线
  • 代码块有圆角和边框
  • 表格表头是小字大写

❌ 如果没生效，你会看到：

  • h1 标题和普通文字一样，没有粉红色
  • 所有元素挤在一起，没有间距
  • 基本就是浏览器默认样式
