# Study Hub 端口规范

日常使用只需打开 `http://localhost:8741`。这是唯一标为 Study Hub 的稳定入口。

| 场景 | 端口 | 说明 |
|---|---:|---|
| Study Hub 稳定版 | 8741 | 日常使用、浏览器扩展、桌面端与 MCP 默认连接地址 |
| Study Hub 开发后端 | 8742 | 仅开发工作树使用，可与稳定版同时运行 |
| 前端开发 | 5173 | Vite 手动开发服务器；端口占用时直接报错，不自动改号 |
| 前端自动化测试 | 5180-5189 | 测试专用范围，不是日常访问入口 |

其中 `5180` 用于工作台自动化测试，`5181` 用于首页自动化测试，`5182` 用于内容解析图文教程自动化测试。

创作中心的 Docker 工具、浏览器桥接和旧的独立服务都有各自的集成端口。它们按需启动，但不属于 Study Hub 主入口，也不应出现在日常启动提示中。

## 使用规则

1. 不在启动命令中临时指定未登记端口。
2. 核心端口已被其他进程占用时，先处理冲突进程，不能改用随机端口。
3. 新增前端自动化测试时，从 `5180-5189` 中分配，并在 `frontend/src/config/ports.js` 登记。
