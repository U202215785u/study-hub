## 💡 提示

1. **安装后重启 Claude Code / Kimi Code CLI** 使 Skill 生效
2. **Skill 之间可以组合使用**：先用 Last30Days 研究选题 → 用 Claude YouTube 写脚本 → 用 Marketing Skills 写社媒文案
3. **自定义配置**：大多数 Skill 支持在项目根目录创建配置文件自定义行为
4. **查看帮助**：安装后在 CLI 中输入 Skill 名称或 `/help` 查看可用命令
