# 内容解析 ASR 错误与重试

## ASR 200

当火山引擎请求返回 HTTP 200，但没有返回业务成功码 `20000000` 或可用转写结果时，解析器会记录：

- 错误码：`PARSER-ASR-2001`
- 原因：火山引擎 ASR 失败

这表示请求到达了服务，但语音识别结果没有成功返回，HTTP 200 不代表转写成功。

## 自动重试

抖音解析首次精确命中“火山引擎 ASR 失败：200”时，会自动完整重解析一次，包括重新下载视频、提取音频和发起 ASR 请求。工作台会显示“正在自动重新解析（第 2 次）”。

第二次仍失败时，以第二次结果作为最终诊断，并停止重试。配置缺失、视频下载失败、ffmpeg 失败和无语音等其他错误不会触发这条自动重试规则。
