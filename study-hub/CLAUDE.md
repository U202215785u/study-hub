# Study-Hub

> 全局协议见根目录 `CLAUDE.md`。本文件仅补充 Study-Hub 子项目特有路径。

## Study-Hub 文件地图

```
backend/                    ← FastAPI 后端（端口 8741）
frontend/                   ← Vue 3 + Vite 前端
extension/                  ← Chrome MV3 浏览器扩展
mods/                       ← 独立模块（learning, suit）
project-memory/             ← 模块状态记忆
    [模块]/状态.md           ← 模块当前状态
    [模块]/问题.md           ← 模块已知问题
    [模块]/决策.md           ← 模块决策记录
    项目索引.md              ← 本项目全局速查
    状态.md                  ← 全局优先级与健康度
    决策.md                  ← 全局决策日志
    问题.md                  ← 全局问题清单
```
