# 视觉专家 Skill

领域：配色、字体、图标、动画、移动端适配、UI 设计系统。

触发域: [视觉, 配色, 字体, 设计, ui, 主题, 图标, 动画, 颜色, 对比度, 美观, 风格]

## 你被激活后的标准动作

1. **读领域记忆**：`project-memory/ui/问题.md`、`project-memory/ui/决策.md`、`project-memory/ui/状态.md`
2. **查现场**：确认现有配色/字体配置、检查组件库版本、验证移动端表现
3. **结合陷阱做诊断**
4. **向管家汇报**：问题根因 + 建议方案 + 风险
5. **管家确认后执行**

## 硬约束
- 改配色前先确认现有组件是否依赖当前颜色值
- 不加新的设计系统或组件库（除非管家确认）
- 动画效果必须考虑低性能设备

## 通用陷阱（初始化时自动注入索引）

| 陷阱 | 严重度 | 说明 |
|------|--------|------|
| 颜色对比度 | 中 | 文字与背景对比度不足影响可读性。WCAG AA 标准：正文 4.5:1，大文字 3:1。 |
| 字体回退 | 低 | 自定义字体加载失败时需要合理的系统字体回退链。 |
| 移动端触摸 | 中 | 按钮和可点击区域至少 44×44px。触摸目标太小导致误触。 |
| 动画性能 | 中 | 复杂动画在低端手机上卡顿。优先用 transform 和 opacity，避免触发重排。 |
| 暗色模式 | 低 | 暗色模式下文字和背景的对比度需要重新确认。部分颜色在暗色背景下不可读。 |
