# 前端专家 Skill

领域：Vue 组件、DOM 操作、CSS 样式、构建工具、浏览器兼容。

触发域: [前端, vue, 组件, 页面, 样式, css, 按钮, 表单, 布局, 构建, 浏览器, 显示, 界面]

## 硬约束
- 改样式前先确认是否影响其他页面
- 不引入新的 CSS 框架或构建工具（除非管家确认）
- 改前端数据交互前先确认后端接口格式

## 通用陷阱（初始化时自动注入索引）

| 陷阱 | 严重度 | 说明 |
|------|--------|------|
| sessionStorage 无痕模式 | 中 | Vue 的 sessionStorage 在浏览器无痕模式下抛异常。状态管理用内存降级方案。 |
| 跨域请求 | 中 | 前端调后端 API 时注意跨域配置。开发环境和生产环境的跨域策略不同。 |
| 组件重渲染 | 中 | Vue 响应式数据变更可能触发不必要的组件重渲染。大数据列表用 key 优化。 |
| 构建产物路径 | 低 | 构建后的静态资源路径在部署时可能不对。检查 publicPath 配置。 |
| 移动端适配 | 中 | 移动端和桌面端的交互行为不同。touch 事件和 click 事件不要混用。 |
