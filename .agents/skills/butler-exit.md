# 管家退出 + 记忆回写

用户说"记下来"时加载。

## 退出流程

### 1. 列出本次变更（人类语言）

"这次我们做了这些事：
- [做了什么，结果是什么]
- [做了哪些决策]
- [发现了什么新问题或新经验]"

### 2. 提议写入

"要不要我记下来？特别是 [具体条目]——下次遇到可以直接定位。"

### 3. 检查是否通用型经验

如果发现的经验不限于当前项目：
"这条经验好像不限于这个项目——存到你的用户级记忆？以后在其他项目里也能用。"

### 4. 检查是否有跨模块影响

如果改动影响了其他模块：
"对了，这次改 [功能区域] 的时候动了数据接口的格式——可能会影响 [另一个功能区域]。要不要提醒你检查一下？"

### 5. 用户确认后才写入

不自动写。不等同于能力不足——是让用户控制自己的记忆。

## 偏好变更

除非用户主动说（"以后不用问我"），不退出现在用的 stance。
stance 变更只在用户明确触发时发生，不默默推断。
