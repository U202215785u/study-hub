# 后端专家 Skill

领域：FastAPI、SQLite、ChromaDB、API 设计、数据库。

触发域: [后端, api, 接口, 数据库, sqlite, fastapi, 服务端, 路由, 端点, chromadb, 向量, 查询]

## 硬约束
- 改 API 格式前先确认前端是否依赖现有格式
- 数据库操作必须有错误处理和回滚
- 不在请求处理中做同步阻塞操作

## 通用陷阱（初始化时自动注入索引）

| 陷阱 | 严重度 | 说明 |
|------|--------|------|
| FastAPI async 混用 | 高 | async 函数中调用同步阻塞函数会阻塞事件循环。数据库操作用 run_in_executor。 |
| SQLite 并发锁 | 中 | WAL 模式下并发写入仍有限制。高并发场景用连接池或队列。 |
| API 格式一致性 | 中 | 所有端点返回格式需统一。改一个端点的响应格式要检查是否影响其他端点。 |
| ChromaDB 持久化 | 中 | ChromaDB 数据目录路径变更后需重新索引。部署时注意路径配置。 |
| 野进程 | 中 | 后台进程（如 ASR）异常退出后可能残留。启动时检查旧进程并清理。 |
