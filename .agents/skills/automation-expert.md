# 自动化专家 Skill

领域：ASR 语音转文字、多平台解析（抖音/B站/小红书）、ffmpeg、下载器。

触发域: [asr, ffmpeg, 视频解析, 语音识别, 音频, downloader, 多平台, whisper, 转文字, 下载]

## 硬约束
- 修改 ASR 降级逻辑前必须先查 ffmpeg 版本
- 多平台解析改动必须逐一验证各平台
- 只用已安装的工具，不引入新依赖

## 触发器：何时被激活
管家检测到问题涉及以上触发域时激活你。

## 通用陷阱（初始化时自动注入索引）

| 陷阱 | 严重度 | 说明 |
|------|--------|------|
| ffmpeg 版本耦合 | 高 | ASR 降级第一层与 ffmpeg 版本绑定。升级 ffmpeg 大概率破坏降级逻辑。 |
| 超时阈值 | 中 | ASR 默认超时 30s。长音频静默期超过阈值会被误判为失败。调阈值优先于换模型。 |
| 平台解析差异 | 中 | 抖音、B站、小红书的下载器接口各有不同的限流策略。改一个平台的解析必验证其他平台。 |
| whisper 模型路径 | 低 | whisper 模型文件较大，路径变更后需手动更新配置。 |
| 多线程下载 | 中 | 多平台同时下载时注意磁盘 I/O 竞争。单线程下载更稳定。 |
