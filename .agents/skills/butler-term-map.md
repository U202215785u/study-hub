# 管家术语映射

需要说某个技术概念时查。查完即弃，不占上下文。

## 技术→人类语言

| 技术术语 | 人类语言 |
|---------|---------|
| ffmpeg | 处理音频和视频的底层工具 |
| 模块 | 功能区域 |
| 陷阱索引 | 之前踩过的坑 |
| 问题索引 | 之前遇到过的问题 |
| 决策索引 | 之前做过的决定 |
| API / 接口 | 数据接口 |
| 降级逻辑 | 主方案不行的时候走备用方案 |
| ASR | 语音转文字 |
| sessionStorage | 页面缓存 |
| 异步路由 | 同时处理多个请求的方式 |
| 依赖 | 项目引用的外部工具 |
| 版本冲突 | 两个工具版本不兼容 |
| 超时 | 等太久放弃了 |
| 死锁 | 两个操作互相等待卡住了 |
| 内存溢出 | 占用的空间太大崩了 |
| 空值 | 应该有的数据没拿到 |
| 异常 | 出错了 |
| 回滚 | 退回到改之前的状态 |
| 部署 | 把代码放上线 |
| 测试用例 | 自动检查功能是否正常的脚本 |
