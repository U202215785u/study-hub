## 3. 实施契约

### 3.1 Motion

- Vue 对象属性必须使用 `:while-hover="{ y: -2 }"`、`:while-press="{ scale: 0.98 }`；禁止把对象写成字符串。
- 首页用 `MotionWrapper` 包裹 widget 时，内部组件必须同时保留 `v-bind="propsFor(widget.id)"` 和 `v-on="listenersFor(widget.id)"`，不能切断现有业务事件。
- reduced-motion 同时覆盖初始读取和媒体查询 `change` 更新；测试只断言结构和终态。
- Storybook decorator 与组件内部统一 `user` 策略，不产生两个互相矛盾的默认值。
- `MotionWrapper` 仅是 Phase 1B 候选，不得在 Phase 1A 任务中假定已经安装。

### 3.2 背景模式

- `preferredMode` 是唯一持久化字段；`resolvedMode` 和 `fallbackReason` 是运行时状态。
- 默认和所有失败路径都是 CSS；`auto` 只有用户明确打开动态背景时才生效。
- 异步组件加载失败必须显式把 `resolvedMode` 设为 `css`，不能以 `undefined` 结束并留下空层。

### 3.3 WebGL 生命周期

- `useWebglSupport` 返回可写的本地状态；探测函数可注入，测试和 Story 不共享不可重置的模块缓存。
- 探测产生的临时 context 必须释放，或直接在实际渲染 canvas 上探测并交给 renderer 管理。
- `initBackground` 统一返回 `{ renderer, resize, stop, dispose }`；调用方使用平面契约。
- 初始化器负责注册 context、visibility 和尺寸监听；`stop` 只暂停帧循环，context restored 通过显式 `restart` 恢复，visibility 恢复不得绕过 context lost 状态。
- `dispose` 先停循环并移除事件，再断开 ResizeObserver、释放 renderer/context 资源并归还 slot。
- context lost 立即 `preventDefault()`、停帧并转 CSS；明确恢复流程最多三次。
- slot 驱逐先删除记录再通知真实实例 stop/dispose；正常 `releaseWebglSlot` 只删除记录，不调用 `onEvict`。

### 3.4 CSS 与可访问性

- 背景位于 scaled stage 内 `absolute; inset: 0; z-index: 0`，所有背景层 `pointer-events: none`、`aria-hidden="true"`。
- 编辑态根节点带 `bento-background--static`，光斑、ring 和噪点动画暂停并清除 `will-change`。
- 玻璃拟态必须有实心 fallback；按静态背景、blur 12px、实心卡片顺序降级。
- reduced-motion 与 reduced-transparency 是独立终态，分别验证。

## 4. 度量与兼容性口径

每个候选方案必须报告四项：入口 chunk gzip；首次打开 Home 所需全部 JS 请求 gzip 总和；启用模式新增异步 chunk gzip；Electron `file://` 下 minified 字节数和解析耗时。懒加载不等于首次首页成本为零。

| 结论类型 | 可使用的表述 |
|---|---|
| 静态推断 | 根据代码、规格或浏览器版本映射推断；不能写成实测 |
| 构建实测 | 有命令、产物、环境和日期；必须给出实际数字 |
| Electron 实机验收 | 目标 Electron 成功启动并完成机器测试；当前文档尚未达到此状态 |

固定项目门禁：活跃 WebGL 目标不超过 2、硬上限 3；合成层目标不超过 18、硬上限 22；目标 Electron 机器录制 5 秒并分别检查编辑拖拽和普通静置长帧；玻璃超预算按既定顺序降级。
