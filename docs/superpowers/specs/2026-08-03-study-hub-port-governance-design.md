# Study Hub 端口治理规范

## 目标

让使用者只需记住稳定入口 `http://localhost:8741`，同时让稳定版、开发版和自动化测试能够并行运行，且不再依赖随机或未登记的端口。

## 固定分配

| 类别 | 端口 | 适用范围 | 面向使用者 |
|---|---:|---|---|
| 稳定后端 | 8741 | 默认启动脚本、Electron、浏览器扩展和 MCP | 是，唯一日常入口 |
| 开发后端 | 8742 | 开发工作树 | 否 |
| 前端开发服务器 | 5173 | 手动前端开发 | 否 |
| 前端自动化测试 | 5180-5189 | Playwright 和视觉测试临时服务器 | 否 |

端口 `5174`、`5178` 和其他未登记的前端端口不得再作为测试默认值、启动提示或文档入口。

## 附属服务

创作中心 Docker 服务（如 Postiz、n8n、Ghost、Uptime Kuma）保持其产品默认端口。它们是可选服务，不属于 Study Hub 核心入口，必须在独立服务清单中说明，不能出现在主启动脚本的成功提示中。

浏览器桥接和历史独立服务使用的端口同样属于集成端口，不得作为主站或开发站端口分配。

## 配置和启动规则

1. 核心端口必须从集中配置读取；禁止在测试脚本中直接写入临时端口。
2. 启动稳定版、开发版或前端开发服务前，先检查目标端口。
3. 端口已被本项目对应服务占用时，复用并显示其地址；被其他进程占用时，明确报错并显示端口与进程号，绝不回退到随机端口。
4. 测试端口只允许使用 `5180-5189`。测试进程必须由测试命令显式传入端口，避免和手动前端开发的 `5173` 冲突。
5. README、批处理文件和桌面端状态中只将 `8741` 标为“Study Hub”；`8742` 标为“开发后端”；`5173` 标为“前端开发”。

## 落地范围

- 新增前端端口常量模块，供测试脚本读取。
- 更新测试脚本中的端口默认值。
- 为前端启动补充端口占用的可读错误信息。
- 更新启动说明和端口表。
- 不修改可选 Docker 服务的端口，也不停止任何正在运行的服务。

## 验收标准

- `8741` 和 `8742` 可同时监听且对应不同的运行目录。
- 标准前端开发固定使用 `5173`。
- 所有前端测试默认端口均落在 `5180-5189`。
- 主 README 和启动提示不再把测试或附属服务端口描述为 Study Hub 主入口。
