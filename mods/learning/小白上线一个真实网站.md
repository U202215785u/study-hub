# 🌐 小白上线一个真实网站 — 从零到上线实战路线

> 目标：用最短的时间、最少的必要知识，让一个真实的网站跑在互联网上。不学全套编程，只学上线一个站需要的部分。

---

## 核心理念

**你不是在学「成为程序员」，你是在学「让一个网站上线」**。这两件事的差别就像「学造车」和「学会开车」——你只需要学会开车。

**最小必要知识原则**：只学让网站上线必须的东西，其他的以后再说。遇到不懂的就问 AI，但你必须知道自己在做什么。

**全程 AI 辅助**：代码让 AI 写，但你负责做决定、检查结果、把东西串起来。

---

## 总体路线

```
Day 1  · 准备工作        —— 注册账号、装好工具、理解互联网基础
Day 2  · 做出第一个页面   —— HTML+CSS 入门，AI 辅助写个人主页
Day 3  · 让页面变好看     —— Tailwind CSS + 响应式，手机电脑都好看
Day 4  · 部署上线         —— Vercel 一键部署，网站可以被全世界访问
Day 5  · 搞定域名         —— 买域名、绑定、HTTPS，拥有自己的网址
Day 6  · 做一个完整网站   —— 多页面产品站（Landing Page）
Day 7  · 收尾和总结       —— 回顾、优化、发布分享
```

- 什么是「部署」？——把你的网页文件放到服务器上，让别人能访问

## Day 2 · 做出第一个页面

**今日目标：用 HTML + CSS 做一个能在浏览器里打开的页面。**

### 核心概念（理解即可，不需要背）

- **HTML** 是网页的骨架——决定「有什么内容」：标题、段落、图片、按钮
- **CSS** 是网页的衣服——决定「长什么样」：颜色、大小、位置、间距
- **标签（Tag）** 是 HTML 的基本单元：`<h1>` 是大标题，`<p>` 是段落，`<img>` 是图片
- **类名（Class）** 是 CSS 用来选中 HTML 元素的：`<div class="hero">` → `.hero { color: red; }`

### 动手实践

**步骤 1**：在电脑上创建一个项目文件夹 `my-website`，在里面创建 `index.html`

**步骤 2**：让 AI 帮你写一个个人主页，用这个提示词：

```
帮我写一个纯 HTML+CSS 的个人主页，要求：
1. 有一个大标题是我的名字
2. 有一句个人介绍
3. 有一个头像位置（先用占位图）
4. 有 3 个技能标签
5. 有联系方式
6. 全部代码写在一个 index.html 文件里（CSS 写在 style 标签里）
7. 背景色用深色、文字用白色，现代简约风格
```

**步骤 3**：把 AI 生成的代码粘贴到 `index.html`，双击用浏览器打开。看到了吗？这就是你的第一个网页！

**步骤 4**：让 AI 逐行解释代码：

```
逐行解释这段 HTML/CSS 代码在做什么，用简单的比喻。
哪些标签是必须有的？哪些是装饰用的？
```

**🔍 今日自查**：
- [ ] 我的 `index.html` 能双击用浏览器打开
- [ ] 我能指出代码里哪个是 HTML（结构）、哪个是 CSS（样式）
- [ ] 我知道 `<head>` 和 `<body>` 的区别
- [ ] 我知道 `class` 是干什么的
- [ ] 我能改一个 CSS 颜色值，刷新浏览器看到变化

## Day 3 · 让页面变好看 + 响应式

**今日目标：用 Tailwind CSS 让页面专业起来，手机和电脑都好看。**

### 核心概念

- **Tailwind CSS** 是一种写 CSS 的新方式——不需要写 CSS 文件，直接在 HTML 标签上写类名
- **响应式**：同一个网页在手机上（窄屏幕）和电脑上（宽屏幕）自动调整布局
- **Tailwind 响应式前缀**：`md:` 表示中等屏幕以上，`lg:` 表示大屏幕

### 动手实践

**步骤 1**：创建一个新的项目（用 Node.js 初始化）：

```bash
# 在终端里执行以下命令：
mkdir my-landing
cd my-landing
npm init -y
npm install tailwindcss @tailwindcss/cli
npx tailwindcss init
```

**步骤 2**：创建 `src/index.html`，让 AI 帮你写一个 Tailwind CSS 的 Landing Page：

```
帮我写一个用 Tailwind CSS CDN 版的单页 Landing Page，要求：
1. 全屏 Hero 区域，大字标题 + 副标题 + 一个 CTA 按钮
2. Features 区域，3 列展示 3 个功能（图标 + 标题 + 描述）
3. 页脚 Footer
4. 响应式：手机上 3 列变 1 列堆叠
5. 用现代配色（indigo 或 blue 系）
6. 所有代码写在一个 HTML 文件里，Tailwind 用 CDN 引入：
   <script src="https://cdn.tailwindcss.com"></script>

主题：一个 [你选择的主题，比如：在线工具箱 / 宠物社区 / 读书笔记]
```

**步骤 3**：在浏览器里打开，然后按 F12 打开开发者工具，点左上角的手机图标切换成手机视图——看看页面怎么自动适配手机屏幕的。

**步骤 4**：让 AI 教你改：

```
我的 Landing Page 在哪里改：
- 标题文字、按钮文字？
- 主色调（蓝色改成绿色）？
- Features 的数量（加一个或删一个）？
```

**🔍 今日自查**：
- [ ] 我能创建文件夹、在里面创建 HTML 文件、用浏览器打开
- [ ] 我的页面在手机视图（F12 手机模式）下布局自动变化
- [ ] 我知道 Tailwind 的类名大概是什么意思（比如 `text-2xl` = 文字2倍大）
- [ ] 我能改一个 Tailwind 类名（比如 `bg-blue-500` 改成 `bg-green-500`）并看到变化

## Day 4 · 部署上线——让全世界能访问

**今日目标：把网站部署到 Vercel，获得一个公开 URL。**

### 核心概念

- **部署** = 把你的 HTML 文件放到互联网上的服务器，让别人通过 URL 访问
- **Vercel** = 一个免费的服务，你推代码到 GitHub，它自动部署
- **Git** = 版本控制工具，记录你的代码每次改动
- **GitHub** = 代码托管平台，你的代码存在上面

### 动手实践

**步骤 1**：安装 Git

去 [git-scm.com](https://git-scm.com) 下载安装。装完后打开终端输入 `git --version` 确认。

**步骤 2**：把你的项目变成 Git 仓库并推送到 GitHub

```bash
# 进入你的项目文件夹
cd my-landing

# 初始化 Git
git init
git add .
git commit -m "我的第一个网站"

# 推送到 GitHub（先在 GitHub 网页上创建一个新仓库，名字叫 my-landing）
git remote add origin https://github.com/你的用户名/my-landing.git
git branch -M main
git push -u origin main
```

**步骤 3**：在 Vercel 上部署

1. 打开 [vercel.com](https://vercel.com) 登录
2. 点击 "New Project"
3. 选择你刚推的 `my-landing` 仓库
4. 直接点 "Deploy"（不需要改任何配置）
5. 等 1 分钟，你会得到一个 URL 类似 `my-landing.vercel.app`

**步骤 4**：在手机上打开这个 URL

用手机浏览器访问 `my-landing.vercel.app`——你的网站上线了！

**步骤 5**：学会更新网站

改了代码以后：
```bash
git add .
git commit -m "更新了XXX"
git push
```
Vercel 会自动检测到 GitHub 更新，自动重新部署（约 1 分钟生效）。

## Day 5 · 搞定域名——拥有自己的网址

**今日目标：买一个域名，绑定到你的网站。**

### 核心概念

- **域名** = 网站的地址，比如 `mycooltools.com`
- **DNS** = 域名系统，把域名翻译成服务器的 IP 地址（就像电话本把名字翻译成电话号码）
- **HTTPS** = 浏览器地址栏里的🔒，表示数据传输是加密的，安全

### 动手实践

**步骤 1**：买一个域名

推荐域名注册商（选一个）：
- **Namecheap**（[namecheap.com](https://namecheap.com)）：国际站，英文界面，便宜
- **阿里云万网**（[wanwang.aliyun.com](https://wanwang.aliyun.com)）：国内站，中文，需要实名认证
- **腾讯云**（[dnspod.cn](https://dnspod.cn)）：国内站，方便

选域名技巧：
- `.com` 最通用，但好名字基本都被注册了
- `.me`、`.io`、`.xyz` 便宜好用
- 短一点、好拼、好记
- 预算 30-80 元/年

**步骤 2**：在 Vercel 上绑定域名

1. 打开 Vercel 项目 → Settings → Domains
2. 输入你买的域名 → Add
3. Vercel 会告诉你需要添加什么 DNS 记录
4. 去你的域名注册商后台，添加 Vercel 要求的 DNS 记录
5. 等几分钟到几小时（DNS 生效需要时间）
6. 刷新 Vercel Domains 页面，看到 "Valid" 就成功了
7. Vercel 自动帮你配好 HTTPS（免费的 SSL 证书）

**步骤 3**：测试

在浏览器输入你的域名，能看到你的网站——就是成功了！

**🔍 今日自查**：
- [ ] 我有一个自己的域名
- [ ] 输入域名能访问我的网站
- [ ] 浏览器地址栏显示🔒（HTTPS 正常）
- [ ] 我大概理解 DNS 做了什么（域名 → IP 地址的翻译）

## Day 6 · 做一个完整的网站

**今日目标：做一个多页面的真实产品站。**

选一个方向（挑你感兴趣的）：

| 方向 | 内容 |
|------|------|
| 个人作品集 | 关于我、我的项目、联系我 |
| 产品 Landing Page | Hero区、功能介绍、价格表、FAQ、CTA |
| 在线简历 | 经历、技能、项目经验、教育 |
| 小型工具箱 | 首页 + 几个在线工具页面 |

### 动手实践

**步骤 1**：用 AI 设计网站结构

```
我要做一个 [你的方向]，帮我设计一下网站应该有哪些页面，
每个页面有什么内容。用列表告诉我。
```

**步骤 2**：让 AI 生成每个页面

```
帮我写一个完整的 [页面名] 页面，用 Tailwind CSS CDN。
要求：
- 响应式设计
- 现代简约风格
- 包含 [具体的元素]
```

**步骤 3**：串起来

创建多个 HTML 文件，用 `<a href="about.html">关于我</a>` 链接到一起。

**步骤 4**：部署更新

```bash
git add .
git commit -m "完成多页面网站"
git push
```
