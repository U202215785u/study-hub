模块工作台的数据流

默认外观来自 Figma；用户配置只改变模块的显示、顺序和受约束尺寸；真实内容由现有业务接口提供。

Figma 默认布局首次进入、配置失效或用户点击“恢复默认”时使用
＋
本地布局配置保存显示模块、顺序、尺寸和配置版本
↓
Module Registry声明模块名称、组件、允许尺寸、容量和入口
→
Layout Store校验配置、迁移旧版本、自动排位和持久化
→
Bento Grid按 16:9 流式比例容器渲染；拖动时只进入合法槽位
↑
真实业务数据知识库、自动化、DDL、手账、创作和工作流接口
→
View-model Adapters把不同接口转换为各 Widget 的稳定数据结构，不改变布局
layoutVersion: 1 modules: [ { id: "work-heatmap", visible: true, size: "2x2", order: 0 }, { id: "calendar-agenda", visible: true, size: "1x2", order: 1 }, { id: "today-focus", visible: true, size: "1x3", order: 2 } ]

1默认即 Figma

用户没有自定义时，首页必须与“改3”空间结构一致，模块化能力不能改变默认视觉。

2固定容量

每个 Widget 声明最多展示条数；超过部分进入“查看全部”，卡片不因真实数据无限长高。

3受约束拖动

编辑模式中可以增减和排序；尺寸只能从模块允许列表选择，网格自动处理碰撞。

4可靠恢复

配置损坏、版本不兼容或模块下线时跳过无效项，并提供“一键恢复 Figma 默认布局”。

5未来可同步

第一阶段保存到本地；存储接口与布局数据分离，后续可切换为工作区或账号同步。
