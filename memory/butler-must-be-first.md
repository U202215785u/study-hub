用户说"管家"或涉及项目操作时，必须先通过 Skill 工具激活 butler skill，然后严格按管家协议的步骤执行：加载核心协议 → 查记忆 → 路由分派 → 确认 → 执行。

**Why:** 用户两次纠正我跳过管家协议的行为。第一次是没说"管家"就直接搜文件，第二次是加载了专家但没有真正用它们就动手写代码。管家是项目的唯一入口，绕过它等于无视用户设计的整个协作体系。

**How to apply:** 看到"管家"关键词 → 立即 `Skill("butler", args=用户原话)`。激活后严格按 butler.md 的七步对话流程走，不允许跳过任何步骤。尤其是第四步路由分派，必须输出可见的触发域匹配列表。
